# G3 数据质量、有效动作和下一轮路线反馈

本轮是受控标定和数据管线诊断，尚无真实物体视频材质推断或预测场桥稳定胜出的结论。后续详细方案见 `G3_REALISTIC_DATA_V2_ZH.md`。

## 实际结果

- 5 组可见形变配置，15 次实际细网格求解完成。24→32 级全场变化约 1.37%，32→48 级约 1.06%，两次端面响应也均低于预设 3% 门槛。32 级用于小样本渲染，48 级为局部参照；这不是连续体误差上界。
- 恒载 200 步对照中，稳态判据使软/硬两组分别在 48/40 步结束，步数减少 76%/80%；最终场相对误差为 1.1303e-5 / 2.5202e-12。实际墙钟加速仅约 1.19/1.46 倍，启动、写盘及并发竞争仍有成本，不能宣称整体 4–5 倍提速。
- 代表恒载视频按真实运动选择帧后，可裁去 181 个尾部静帧，将有效片段从 4 秒缩到约 0.38 秒。时间戳不变，不人为加速动力学。加载/卸载、恢复等动作仍保留；蠕变/松弛数据另设采样规则。
- 动态 dt=10→5ms 时，软/硬材料轨迹差异为 4.9895%/1.6263%；进一步 5→2.5ms 后为 **6.8481%/2.4078%**。软材料不通过 5% 时间收敛门槛，**暂不作为动态监督**；更细步检查揭示前一次临界通过不可靠。隐式 BDF1 数值耗散不能当作材料阻尼。
- 无遮挡/中/重遮挡使用同一物理轨迹、相机和表面纹理配对，保存遮挡/可见掩码与对应流。当前仅为图像空间遮挡增强，没有真实手、夹具或三维接触。
- E 和外力同时 ×4 的实际稳态位移差约 3.8e-16，说明这项准静态协议下未知力与绝对刚度具有尺度歧义；不能据此否定标定动态信息的作用。
