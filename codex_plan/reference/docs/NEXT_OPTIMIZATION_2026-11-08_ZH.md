# A800-2：从可运行系统到可验证的材质推断

本轮优先顺序为：先加强运动证据并做匹配消融，同时修接触数据质量；再将视频表征接到独立引擎头，最后以未见作用的响应而非跨引擎参数数值直接比较。科学目标是检验可行性，不能预先保证优于所有无桥模型或达到在线优化精度。

## 现有结论与这次实际改动

旧 G1f 的验证 MAE：RGB 0.80545，预测场桥 0.80253，普通特征桥 0.80246，真场上界 0.69032。预测场未显示独立收益。其流场甚至不如训练集常量，接触召回高而精度只有约 6.17%。因此，本轮不重开旧 FULL，也不通过扩大骨干来掩盖场表示问题。

`motion_field` 新结构在同一冻结 DINOv3 patch 特征上显式构造首帧偏离、相邻差分和外观三路，保留 4×4 空间单元的时序注意力，之后再做跨视角/时间汇总。这些差分是特征变化，不冒充米每秒速度。padding 在差分和注意力前屏蔽；空视角不会产生 NaN。旧 `model.py` 字节不变，继续满足历史特征缓存契约。

M1 四组从相同随机种子、同一初始化方案开始，均有 3,050,909 个可训练参数、同一冻结骨干与采样、同一优化器、有效 batch=8、最多 20 轮与相同验证早停策略。B：无场损失、无桥；C：场辅助监督但无桥；D：预测场桥；G：等通道普通特征桥且有同样场辅助监督。C/D/G 使用 BCE+Dice 接触损失与 0.1 场权重。B 的无场损失是其定义的一部分，不能将 C 的收益一概算成 bridge 收益。

首轮只用 512 train / 128 val、物体隔离、seed17。测试集不参与。D 必须相对 B/C/G 中最强者降低至少 2% 验证误差，才进入独立种子与干预测试；路由门槛不是统计显著性或投稿最终结论。若 C 最好，应优先保留辅助监督架构而继续调查 bridge，不给 D 换一个更弱的比较对象。

## 架构路线及进入条件

| 路线 | 目的 | 有限实验与进入条件 |
|---|---|---|
| M1：局部运动＋场桥 | 检验早期空间平均是否丢失形变证据 | 当前 B/C/D/G 同预算诊断；若 no-bridge 更好，保留负结果 |
| M2：可见性置信度＋度量场 | 处理工具/手部遮挡、稀疏接触与可预测性差的应力 | 使用可见对应位移、接触分布与置信度；先过可拟合性及常量/运动特征控制，不强求从单目唯一恢复隐藏应力 |
| M3：共享响应表征＋引擎头 | 解决同名参数不同引擎/本构不等价 | 接 `EngineConditionedHeads`，每个 engine/version/law/mapping/solver 独立规范化；共享头只预测带协议的响应，不输入引擎 ID |
| M4：静态先验＋动态证据 | 静态或运动微弱视频仍可提供信息 | PIXIE/VoMP 作为独立先验；相同先验同时给 no-bridge，单独报告输入与离线预训练成本 |
| M5：前向预测＋少量在线修正 | 更稳妥地接近充分在线拟合效果 | 分别比较随机初始化优化、no-bridge 初始化优化、field 初始化优化和纯前向；同时间/rollout 预算与未见作用评分 |

M1 已暴露 `material_embedding`，但尚未训练视频跨引擎头。G2 的共享头实验使用完整观测场，不等同 RGB 视频成功。必须在报告中保留这一区别。

静态、未知力与未知尺度条件下不保证绝对 E 可辨识。此时输出外观先验、相对柔顺性和不确定性；已知几何/尺度、动作、质量或力的信息增强组才评价相应绝对参数。复合材质输出分区/局部属性，不压成全物体唯一 E。相对软硬排序只在匹配几何、边界、力历史、尺度与本构有效范围的协议内成立。

## 数据生成：修复后才能扩量

G3n 原反力网格差 24→36 为 3.24%，36→48 为 4.47%，均未过预注册 3% 门槛；位移收敛不能替代力收敛。先做 G3h：仅将屏障距离 0.1mm 改为 0.05mm，在 24/36/48 三层重新计算。保留所有原失败结果，不提高门槛。另按接触活跃期统计力平衡，避免近零接触帧的分母使全时段相对残差被误读。该诊断即使通过也不自动授予反力 GT。

数据准入按用途分开：可见位移训练需要几何/尺度、完整时间戳、数值健康、时间/空间收敛和可见性验收；绝对反力/应力监督另需接触离散、单位、平衡与对应误差验收。能量诊断必须区分固体能量、接触屏障、工具/执行器功，端点功不能冒充完整能量守恒。没有通过的量标为缺失，而不是伪造完整标签。

后续小矩阵使用有尺度的不规则实体、完全粘接双材质、加载—保持—卸载与不同作用位置。材质与纹理/载荷分布独立。主要可见运动目标约 8–25px，2–8px 单列难例；用真实相机、接触幅值与几何控制，不放大渲染形变。保留恢复段；静止尾段按动作事件裁减，黏弹保持段不可随意丢弃。GS 外观与实体物理几何分别验收，薄壳、绳、实心软体不共享错误的体积假设。

引擎策略：UIPC 先修接触/分区实体；Warp FEM 保留小应变已知牵引参照；Newton Implicit MPM 为大形变/多材料候选；Boba 为批量弹簧教师候选。新引擎先通过相同 SI 标定、时间步/分辨率/本构极限及响应对齐，不能把可运行示例当质量优势。官方 Newton 当前 HEAD 依赖 Warp>=1.17，A800-2 驱动为 535.129.03，而官方新版本说明给出更新驱动范围；因此须隔离环境验证版本兼容，不能升级现有 Warp/UIPC 环境来碰运气。Boba 新默认 CUDA13.2 栈也不直接覆盖现有 CUDA12.6 训练环境。

## 公平比较与最终可行性证据

1. **输入契约**：分别建立 RGB、RGB＋已知几何/尺度/动作、RGB-D/标定力三条轨道。相机、几何、力/质量、分割、轨迹教师及静态先验的信息都在表中显式列出。额外信息相同的 no-bridge 才是主控制。
2. **划分契约**：同物体、同 GS/几何资产、同一物理轨迹的视角/遮挡/材料变体整体分组；优先按未见物体、作用位置、布局和动作留出。当前 val 只选方案，测试协议冻结前不读取测试效果。
3. **质量契约**：原生参数误差只在相同引擎域内报告；主比较为未见作用的归一化位移/轨迹误差、可见/遮挡分桶、失败率、尾部与区间校准。物理重放使用同几何/边界/尺度，本构无法拟合的误差另列。
4. **成本契约**：在线方法报告重建、跟踪、初始化、拟合、渲染和失败的端到端成本，以及 0/10/30/120/600 秒与 rollout 次数曲线。前向模型离线训练/教师成本单列；不能将作者设备时间与本机直接做倍数比较。
5. **统计契约**：方向确定后再做 seed17/29/43；以物体为重采样单位做 paired bootstrap，报告 95% CI 和每物体结果。几千帧不当成几千独立物体。改善必须来自最强匹配控制，不能只比旧弱 RGB。
6. **部署证据**：先在已知尺度/有限材质族/可见交互下做真实短视频→原生参数→未见动作重放；再削减输入。若只有 warm-start 能接近充分优化，则结论写为缩短在线优化时间，保留纯前向与混合系统两条结果。

开发目标仍是相对最强匹配 no-bridge 约 30% 的未见动作误差改善，以及在给定信息/预算下接近在线拟合约 10% 的差距。这是方向，不是放宽准入或承诺成果。若场桥没有稳定增益，应调整表示、交互可辨识性或研究结论，而不删除反例。

## 本轮已完成的反馈与下一阶段决定

M1 已全部按验证停滞早停：B 0.703485（最佳第14轮，运行18轮）、C 0.680282（第12轮，16轮）、D 0.682836（第12轮，16轮）、G 0.677941（第14轮，18轮）。D 相对最强匹配 G 反而高约0.72%，不进入大规模/多种子确认。旧架构的分阶段初始化与预算不同，不能把新旧数字差直接当作纯架构增益。

M1a 固定各组最佳检查点，完整覆盖128条验证/10个物体。D 用静帧替换后 MAE 1.07605，观测倒放0.96629，正常0.68284；说明部署输出依赖时序输入，但分布外干预不能证明物理因果。将 D 的桥置零仍为0.68275，预测平均变化仅0.00136个标准化单位。G 同样几乎忽略其桥。桥本身按帧编码后做均值汇聚，置换桥帧顺序结构上不改变结果；这是需要修正的表示限制，而不是一次成功的反事实实验。

物体聚类 bootstrap（10000次）的 D−B MAE 区间为[-0.04806,0.00660]，D−C为[-0.00475,0.01062]，D−G为[-0.00888,0.01711]，均包含0。它们只反映验证选模后的物体重采样不确定性，不含训练随机种子、总体泛化或独立测试证据。

G3h 三层已完成：屏障距离减半后的两级反力差3.63%/5.59%，没有修复网格问题，停止这一扩量路线。活跃接触期节点平衡虽较好，不能替代接触力的网格收敛。下一仿真阶段分成两条：UIPC 检查接触表面积分/离散与边界；隔离环境的新 MPM 后端先做已知牵引、压缩和双材质极限测试。两者均不得绕过现有3%力门槛。通过位移用途验收但不通过力验收的数据，只能提供相应可见位移标签。

D1 已准备20个真实物体，15 train / 5 val，全部逐帧解码并按真实时间戳取16帧，**尚未用于训练**。Deform360 sloth 在任何训练前保留到验证。E1 已取得两个 PhysTwin 场景12个文件（8个可解码视频、4个元数据/划分文件），仅获取所选 ZIP 成员并校验成员 CRC/内容 SHA，未下载整个归档、RGB-D、追踪或运行其官方优化器。

效率方面，M1 单轮中位约30.7–31.1秒，其中训练段约23.8–24.1秒，数据等待约18.3–18.4秒（等待包含在训练段内，不能相加）。首轮2-worker RAM实验含完整float64特征校验，只快1.024倍，因此没有自动开启内存缓存。第二轮排除完整特征求和的主要开销：同样64条完整加载、每帧少量元素校验，2 workers第二遍1.680秒，4 workers 1.183秒，2 workers+4GiB/进程1.211秒；与0 workers的3.264秒分开比较。4 workers相对原2 workers约1.42倍**加载吞吐**，不是训练全流程1.42倍。后续匹配训练优先统一测试4 workers；RAM默认保持0，只有测量收益才启用。缓存保存CPU张量、有界LRU、对增强时修改的mask克隆，避免跨轮污染；预算按每个worker计算，不能当全机上限。

下一阶段具体执行顺序：

1. **M2a 数据验收先于新大模型**：建立相机/可见性/实际时间的对应位移监督，接触与应力独立mask；先做少量训练样本过拟合和未见物体的常量/差分基线。旧RGB应力图不转成Pa。真实视频仅做时序一致性或对应学习，外部评估片段不参与预训练。
2. **M2b 保留场时空结构**：用局部场token与可见性置信度做时序注意力，显式区分直接RGB与场通路；对普通特征控制使用相同聚合器和容量。以冻结RGB的零场锚点、置零/置乱、辅助监督无桥对照判断是否真正在利用场，不依赖把无桥弱化来获得收益。
3. **M3 共享响应＋引擎头**：先对已验收的已知尺度/加载协议接入视频表征；域记录engine/version/law/units/mapping/solver。学习统一探针动作下的响应和不确定性，原生参数由各域头输出。相对排序只在可比的几何/加载条件下作为辅助损失，不跨不同本构混合E标签。
4. **M4/M5 公平真实验证**：PokeFlex优先补充受力/几何证据；PhysTwin同场景只对齐相同输入的轨道。在线对照获得同几何/相机/动作和相同优化预算，比较无桥/场桥初始化以及充分优化，主终点是未见作用响应。只有方向门槛通过后才做3种子和冻结测试。
