# 零场材料系统辨识：实现与实验合同

本路线不预测稠密物理场，不使用接触/光流/应力辅助损失，也没有场或特征反馈支路。它与历史G控制不同：历史G仍接受辅助场监督。当前先用现有固定512训练/128验证、88/10物体、单摄像机16帧和冻结DINOv3-L/16验证实现；最终测试集不使用。

## 已实现

- `DirectVideoModel` 独立继承 `nn.Module`，只实例化冻结帧编码器、特征差分、局部时序注意力、空间位置、材料与后验/本构头；没有场头、场编码器或场反馈。差分是视觉特征差分，不称为速度/应变。
- `FieldFreeDataset` 从既有缓存严格白名单提取features/valid/times；旧缓存虽在磁盘上包含场，但返回值、内存缓存、IPC、GPU及损失中均无fields/field_mask。参数标签按原训练统计编码，不从旧缓存复制目标。后续可生成物理分离缓存，但本轮不改变特征精度。
- 首个有效帧的DINO全局特征训练固定配方ridge先验。训练样本按物体做五折OOF，验证先验只由全部训练物体拟合；先验不是PIXIE/VoMP集成，也不假设外观与旧随机材参存在对应关系。先验残差方差仅为未校准估计。
- 四分量对角高斯混合后验；缺失参数通过边缘化计算联合NLL。点估计为混合均值，评价另保存分量；区间通过精确边缘混合CDF数值反演，不以矩匹配高斯覆盖率冒充混合分布覆盖率。
- 离线教师overlay合同支持每样本1–16个解与权重，限制train-only并要求输入、求解器、拟合协议和响应核验来源。配置未提供准入教师时禁止蒸馏；恢复时检查先验、教师和特征索引SHA。
- 沿用项目逐轮验证、验证材参平台期早停、完整检查点暂停/继续、优化器/RNG恢复、Web队列与逐轮计时。

## 顺序控制

|实验|静态先验输入|参数Huber|混合NLL|物理场或反馈|
|---|---|---|---|---|
|N0_video_point|读取相同文件但内部屏蔽|是|0|无|
|N1_prior_point|物体OOF先验|是|0|无|
|N2_prior_posterior|相同物体OOF先验|是|0.1|无|

三组实例化相同模块、相同初始化与可训练参数数量；N0/N1未训练的后验头不用于可信区间结论。统一seed17、width256/layers2、lr3e-4、batch4×accum2、workers4、最多20轮、patience4/min6。顺序依赖为先验准备→N0→N1→N2→审计，不根据前组效果临时更改后组配方。单种子只作方向与工程诊断；历史强控制继续保留，不能因新控制较弱而删除。

## 离线教师验证的边界

`probe_fieldfree_teacher.py` 在I1已通过的线性小应变夹具上运行：已知几何、加载、尺度、nu=.3和rho=1000，仅拟合E。模拟16帧准静态投影轨迹，加入0.002px噪声；每条由有界逆拟合生成E教师标签，96条训练、24条留出。学生输入压缩轨迹观测和已知力，不是RGB视频，不用于原数据训练。

原GS数据尚未满足可信教师所需的几何/加载与响应核验，因此本轮不注册伪装成“教师蒸馏”的GT回归实验。该路线已完成接口与独立夹具验证；原视频的教师生成、蒸馏及真实新动作验收仍待完成。

## 验证与复现

关键测试覆盖：缓存中毒场无法进入训练、模型无场模块、缺失先验消除、OOF本物体泄漏拒绝、特征来源不一致拒绝、精确混合边缘NLL与分位数、未准入/非训练教师拒绝、完整训练/恢复与SHA变更拒绝。

A800-2完整软件测试为122 passed（12.09秒，8条既有fork警告）；新增测试包括无标签视频输入、时间戳采样与非法时间戳拒绝。软件测试通过不代表材质估计精度通过。

## 首轮结果与后续门槛

三组均已完成并因验证材参停滞早停，可训练参数均为2,128,179，测试集未使用。

|实验|标准化MAE（越低越好）|最佳轮/完成轮|
|---|---|---|
|N0 纯视频|0.766416|10/14|
|N1 首帧先验+视频|0.772903|8/12|
|N2 首帧先验+混合后验|0.779855|8/12|

训练均值常数基线为0.865159，静态ridge独立基线为1.307022。N0较常数降低11.41%；N1、N2相对N0分别恶化0.85%、1.75%。按10个验证物体配对的探索性bootstrap差值区间均跨0，单种子结果不能证明增益或损失具有统计稳定性。历史B1最佳为0.733968，配置/容量不同，仅作背景，不作为匹配的桥接因果对照。

N2每观测参数NLL为1.2800，名义95%精确混合边缘区间实际覆盖89.77%，平均宽度3.2701个标准化单位。E/nu/rho/sigma_y覆盖率分别为93.75%/84.38%/87.50%/100%（最后一项仅46个有效标签）；需要独立校准数据，不能直接将区间称为可靠置信度。N0/N1没有训练后验，其高覆盖/宽区间不构成概率模型效果。

离线教师夹具120例中，96例训练、24例留出；逆拟合教师E平均相对误差0.00130%，学生4.59%，留出幅度的代数响应误差4.72%。仅E未知，其余材料量、几何及力已知；学生看到压缩轨迹与力，并非RGB。线性缩放响应检查不等同于真实新动作仿真验收，不据此准入原GS视频教师。

本轮不自动扩大训练。下一阶段优先：(1) 数据中建立可核验的外观—材性与几何/载荷关系，补足同条件不同材性/同材性不同受力的配对；(2) 对后验做独立物体校准并测区间宽度/覆盖权衡；(3) 在几何、尺度、接触/加载可观测且响应复现通过后生成原视频离线教师，再做同预算蒸馏对照。当前静态ridge较弱，不能据此否定外部静态材料基础模型，但也没有支持直接堆大模型的证据。

三组训练轮用时中位数约12秒，其中数据等待约9.8秒，另有约3.1秒验证。缓存I/O是这一冻结骨干诊断的明显开销；这是既有缓存读取实测，尚未将格式拆分、增加内存缓存或改变精度后的加速冒充已实现结果。

## 单视频推理入口

```bash
python scripts/infer_fieldfree_video.py \
  --checkpoint runs/nf_N0_video_point_seed17/best_material.pt \
  --video /path/to/input.mp4 \
  --output /path/to/material_estimate.json
```

输入只需RGB视频；默认按容器FPS推算秒时间，假设帧间隔固定，取最多16帧。对于不等间隔采样（原数据64帧导出即属此类），添加 `--timestamps-json /path/to/times.json`：文件为覆盖全部源帧的严格递增秒时间数组；入口按采样帧索引取时刻，并减去首帧时刻得到相对时间。时间戳与视频分别记录SHA。固定FPS重编码不能保留原数据真实采样时刻。

DINO权重仍由检查点配置显式提供；N1/N2还校验训练时静态先验文件与full_train拟合权重的SHA，首帧生成先验，不需要该新视频的标签。缺少权重或先验时直接失败，不退回随机模型。

输出为原训练域E/nu/rho/sigma_y估计、本构类别概率、输入与检查点SHA；只有NLL实际训练的模型才输出精确混合边缘95%区间，区间未经真实数据校准。原训练域含义不等于已标定真实物理常数，更不等于其他引擎原生参数。视频解码/前向链路验证与真实世界精度验证分开报告。

真实DINO推理链路已用一个既有验证RGB视频的无损导出核验三组检查点。携带原始物理时间戳时，与保存的批量缓存验证相比，最大标准化参数差分别为N0 0.000977、N1 0.002653、N2 0.000011；不宣称逐位一致。该单片数值核验没有覆盖全部视频；冷启动含加载/编码约8.3–8.6秒，不是常驻模型纯前向速度，也不是真实世界视频准确性测评。
