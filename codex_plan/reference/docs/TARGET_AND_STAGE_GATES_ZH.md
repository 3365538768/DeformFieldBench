# 目标与阶段验收协议

2026-11-07 更新：核心目标是**无在线拟合的 field bridge，在响应质量上接近持续在线仿真拟合方法，并明显超过强无 bridge 方法**。提高参数表格分数只是其中一部分；新交互的仿真响应是最终依据。

## 目标如何落地

开发时先以两项有挑战性的数值目标组织实验：相对最强匹配无 bridge 对照，未见物体/动作的响应误差降低约 30%；相对同信息输入的充分优化在线拟合方法，响应误差差距控制在约 10% 内。它们是开发方向，不是已取得的效果或预先保证的结果。接近零误差时改用预先按测量分辨率确定的绝对容差，避免比例失真。

正式结论必须同时给出逐物体误差、三随机种子结果、成对物体 bootstrap 区间、尾部失败率及成本；不能仅凭均值达到目标就宣布成功。若只有参数改善、响应没有改善，应明确判定最终目标尚未达到。

## 比较对象与信息公平

| 组别 | 方法 | 用途 |
|---|---|---|
| B | RGB 直接回归，无场监督/反馈 | 基础对照 |
| C | 同样 RGB、场监督、骨干和训练预算，但没有预测场反馈 | 核心因果对照 |
| D | 预测场反馈到参数头 | 验证 bridge 本身 |
| E/F | 相同独立静态先验，分别无/有 field feedback | 排除“只靠强先验”的解释 |
| G | 等容量非语义特征反馈 | 排除新增网络容量的解释 |
| O | 同几何、视频、尺度、动作信息，按固定预算在线拟合 | 质量与时间参照 |
| O+D | D 初始化后短预算在线拟合 | 补充系统收益，不混入无在线拟合主结论 |

在线方法分别报告冷启动、热启动、5/20/100 次求解器调用和充分收敛曲线，包含失败和超时。最终迭代预算以测量后的时间档位为准，不能刻意截断强基线。方法需要额外 RGB-D、已知力、真实几何或人工材质标签时单列信息增强组，不能直接称为同条件优劣。

所有方法保持相同可观测时间窗、视角数和分辨率。原工程默认 16 帧是开发设置，原文 64 帧需单独复现/做帧数曲线；不能将不同输入预算所得结果当作严格复现。强无 bridge 对照也要获得同样的超参搜索预算。

## 最终评估的优先级

1. 拟合输入中没有出现的新动作/新接触位置下，三维轨迹误差、表面距离、形变轮廓和回弹/振动响应。按统一物体尺度归一化，并保留 SI 原值。
2. 具有可信测量的样本，比较力—位移曲线、质量与材参；没有真实 E 的物体不伪造参数真值。静态视频单列，输出范围与置信度。
3. 参数误差、相关性、长尾和按本构/刚度/动作分组结果；不删除高误差样本。
4. 从原始视频到参数的总时间、几何/跟踪等前处理时间、GPU 峰值、求解器调用次数及跨动作复用成本。训练/离线生成成本另外报告，评估所需统一重放也另外计时。

同一视频上的重渲染只是辅助指标。拟合视频和新动作验证视频必须不同，且测试动作不能用于优化该物体参数。响应指标使用真实测量/独立重放；旧彩色 stress/flow 图不能直接当作 SI 应力、速度真值。

## 分阶段推进与反馈

| 阶段 | 本阶段实际交付 | 进入下一阶段的条件 |
|---|---|---|
| P0a 数据协议 | 原发布划分精确校验、完整 SHA/CRC/数组/时间审计、对象隔离 val | 不隐式跳过失败样本，明确场标签和单位 |
| P0b 优化验证 | 小规模真实数据 C/D 工程试跑、损失/梯度/吞吐/显存记录 | 可以正常收敛；工程试跑不作为质量结论 |
| P0c 核心证据 | DINOv2-g 上 B/C/D/G 三种子、独立 val 选择和冻结协议 | 未过滤指标与尾部稳定改善；若无收益先查场信息量 |
| P1 静态先验/骨干 | E/F、DINOv3-L/H+、同输入同预算消融 | 收益来源可分离，强 no-bridge 仍显著落后 |
| P2 响应和拟合基线 | 标定引擎、补齐几何、真实/新动作 O 与 D 对比 | 能报告质量—时间曲线、可辨识范围和失败案例 |
| P3 数据扩展/随手拍 | 开放真实数据与复合/壳体/部件数据，手机短视频演示 | 未见材质组合和真实动作验证通过 |

每阶段反馈包括：完成了什么、实际测量、暴露的问题、下一步及是否需要改变路线。收益不理想也立即反馈，不能用更大骨干掩盖。

## 若 bridge 收益不明显，按此顺序诊断

先比较 RGB 与真实场的诊断上界，判断旧彩色标签中是否还有材参信息；上界实验必须独立标识，GT 场不能进入部署推理或主结果。再做语义打乱场、stop-gradient 和 G 控制，区分场语义、辅助监督和额外容量。之后检查接触稀疏、前景占比、逐帧归一化、绝对时间和骨干冻结导致的欠拟合。

若诊断上界也无收益，优先补足可辨识动作、原始度量场和反作用力，并解除阻尼与类别绑定。若上界有效而预测场无效，改进场预测和时空反馈（局部场 token 交互、置信度门控、残差更新），再进行等容量消融。最后才扩大骨干或数据量。

## 当前事实与缺口

- 官方 cleaned split 已明确使用 4,914 个 pack：4,420 原训练、494 原测试。86 个仅有标签的目录不在该协议内；不能直接称为训练丢样。
- 本次读取样本的 run_parameters 给出真实 `frame_dt`、`substep_dt` 和 render_frame_indices，新导入器可恢复相对物理时间。旧缺少这些元数据的包仍显式使用归一化时间。
- HF 发布 ZIP 与代码库未包含原始物体 PLY；用户补充的 Kaggle **第 2 版**已成功补齐全部 108 份 PLY，完成 CRC、哈希、Gaussian 属性和有限值检查。发布 split 的对象统计也为 108，与论文“100 个”描述有差异。尚需核对长度尺度、内部填充及边界，才能声称精确重放。
- 两轮 240 条真实工程试跑已完成，普通/平衡 BCE 均未显示 bridge 的参数收益；详细负结果见 `STAGE_P0_PROGRESS_ZH.md`。尚无显著改善、接近在线拟合或真实物体材参准确性的证据。
