## 4. 原模型的严格场反馈消融怎么做

### 4.1 控制矩阵

先以原论文版本建立下面 C/D 配对；**不能用新 DINOv3 模型的数字替代原论文消融**。保留论文所用三视角、帧采样、数据 split、本构/参数 mask、阶段训练、预训练版本和选模准则。

|---|---|---|---|---|
| B：原 supervised | 按原实现披露 | 按原实现披露 | 无 | 复现历史系统比较，不能单独归因反馈 |
| C：aux-no-feedback | **与 D 相同** | **与 D 相同** | **仅此处关闭** | reviewer 要求的核心控制 |

## 5. 物理损失与训练复现：先修正事实

### 5.1 已完成的源码审计

历史 `logic_model/losses.py` 的实际实现是：输入 `[B,V,C,T,H,W]` 对通道取绝对值均值，再对每个样本的 **V、T、H、W 联合 z-score/聚合**；接触区域内外对比也联合聚合这些轴。它不是每时刻的力平衡，也不是只比较局部空间响应。对 RGB 编码可视化取绝对值均值更不能直接解释为 SI 单位的应力/速度模长。

reviewer 关于恢复振荡的反例成立：单自由度弹性运动 `x=A cos(ωt)` 中，弹性力/应力与位移相关，速度与它相差四分之一周期；固定端可能高应力、低速度。因此不能把正相关或接触区更强说成一般机械规律。可以称特定观测/加载下的经验正则，但要有实验证据和适用范围；否则从推荐目标中移除，不以“弱约束”回避问题。

公开 full-model 默认配置中 `use_phys_loss=false, lambda_phys=0, stage1_use_phys_loss=false`；消融生成器另外提供 λ=0.001/0.01/0.1 的候选。**这只证明公开默认值，不证明论文 Table 1 实际未使用损失**。

两条处理路径：

- 若 checkpoint 与 resolved runtime config 证明主实验未启用：纠正“训练目标必含该项”的表述，说明 Eq.19–21 是未使用的候选/移至讨论；不能把其他配置的结果叫成原模型 loss-off 消融。
- 若主实验确实启用：在相同预算下补全模型 λ=0 重训，对加载中/释放/恢复分别报参数与场误差；资源允许再做 C/D×loss-on/off 的 2×2。不要花 deadline 扫很多 λ。必须区分这项正则与正常的场 GT 辅助监督，删正则不等于删场监督。

新的严格物理残差只有在几何、时间、单位、外力/边界和三维场可得时才有意义。不得在旧 RGB stress/flow 上直接加动量或能量守恒并宣称 SI 物理约束。

## 6. 原仿真可信度：做小而有效的校验，不重造整个数据集

### 6.1 回弹差异不是参数 adapter 就能解决

低于约 5% 与超过 60% 的回弹差异，可能来自材料、接触、阻尼、积分与填充等组合。当前源码存在材料族相关的每子步 damping 设置；例如倍率 0.999、dt=1e-4 对应连续衰减率约 10.005 s⁻¹。**这是数值耗散的可检验线索，不是已确认的唯一根因。** 固定每步倍率再改变 dt，会改变单位物理时间的阻尼；测试步长收敛时应固定物理衰减率，再用 `d=exp(−γdt)` 换算。

不能把新引擎调到 60% 就宣称更正确。Spring-Gaus 的刚度/阻尼与 MPM 的 E/ν 本来也不是相同参数，必须比较有明确初态、几何、质量、接触和材料标定依据的响应。

### 6.2 最小校验套件

| 校验 | 具体设置 | 可回答什么 |
|---|---|---|
| 无碰撞自由落体 | 关闭阻尼/外部 actuator，核对质心 `z=z0+v0t−gt²/2`，使用实际输出时间戳 | 单位、重力、积分和导出时间是否一致；不验证材料本构 |
| 小应变准静态拉伸/剪切 | 规则可控几何、已知 E/ν，测实际内部位移/反力；用同一初态与边界的解析解或独立参考 | 材料系数、边界、模量映射是否合理 |
| 释放/振荡 | 固定几何、密度和小应变材料，记录振幅衰减和周期 | 单位时间数值耗散、恢复是否覆盖数据需要 |
| drop/rebound | 同一球/块体，再选至少两个已公开的 GS 物体；固定高度定义、地面、重力、摩擦、初始速度 | 分离碰撞耗散和几何/填充影响，复现 reviewer 的差异 |
| 数值收敛 | 至少 2 个 dt 与 3 个网格/粒子分辨率，其他物理条件不变 | 响应是否随离散化稳定；不能单靠“不爆炸”证明正确 |

先覆盖弹性校验，再对塑性材料核对残余形变和本构预期；没有合格的参考，不宣称塑性已校准。原则上 ν 接近不可压、细薄结构、大塑性等应单独标为高风险，不能用小应变梁通过覆盖所有场景。

drop 统一记录质心轨迹、落下/回弹高度、首次接触和离地时间、残余形变、数值异常。`sqrt(h_rebound/h_drop)` 只在合适的竖直运动、参考接触高度与外力条件下作为有效恢复系数近似；对持续 actuator、复杂变形和不同接触参考面不能机械套用。

**规划验收线，不是现有结果**：解析运动/小应变响应目标误差 <5%，相邻精细设置的主要响应变化 <5%；若 5–10% 则披露并定位，>10% 不对该区域作定量物性可信度主张。阈值先由算例假设与测量精度确认，不能看测试结果再放宽。需要真实材料的独立测量时，数值收敛只能作为必要条件。

给旧数据按本构、动作、形变幅度和恢复阶段统计可用比例、近静止帧占比、接触可见率、异常/塌陷率、范围覆盖和 label/geometry 关联。既有扫描发现 4,914 有效 pack、108 个对象，与论文“5,000/100”和部分测试数量口径不一致，需要列 ID 清单解释，而不是默默换 split。任何新增筛选都由 train/val 冻结规则，主测试保留失败计数，禁止按方法过滤。

### 6.3 若原设置确实不可靠

公开限制适用范围，删除 fracture/任意动力学支持等超出能力的表述。原始数据保持版本化，并发布 correction manifest；可以另建小规模、受控且校准的 v2 验证集，但其结果必须单列，不能作为原数据已被验证的替身。换用 Warp/FEM/libuipc 可以改善后续任务，却无法自动回答 reviewer 对旧 3DGS–MPM 的质疑。

### 7.1 参数、空间输出与引擎如何对齐

- 仅在本构、单位、静态/动态定义兼容时报告 E/ν/ρ 参数误差，记录 log base 和反变换。不同引擎同名参数不能盲目等同。
- 稠密异质预测与单一全局 GT：第一主表保留其原生预测并评估行为；若增加全局汇总，明确算法并承认体积加权均值不等于有效模量。为了得到响应等价的全局参数而额外拟合，要把拟合计入成本，标为 adapted 结果。
- 只在有共同可辨识 GT 的维度计误差，报告支持覆盖率。缺少 yield/材料族的 baseline 不能以填 GT 方式混进全参数总分。
- 同一测试集、相同初态/作用/相机/渲染器/可见区域；未知 nuisance 不给我们 GT 而给别人估计，反之亦然。若为目标引擎做适配，仅用 train/val 标定。
- 同时报告 pretrained zero-shot 和在同一训练 split 上适配后的结果，标注监督量、公开预训练数据来源、教师/文本/几何特权及可能重叠；不能声称公开预训练总算力完全相等。
- 端到端时间包含解码、分割、重建、特征和适配/优化；另列纯网络延迟、显存、仿真调用数和失败率。已有 3D 资产的 3.59 s 不能与从手机视频开始的总时间直接比较。

### 7.2 在线拟合比较与真实域的最低要求

保留一个**使用同一允许观测、同一初态与引擎的参数拟合**控制：固定几何/边界，优化可比较的材参，显式列出哪些量已知。报告固定预算的误差—wall-time 曲线、多起点与失败率；它是强比较对象，不称绝对 oracle。若我们的预测作为初始化另加优化，这是 hybrid 结果，不能计作纯前馈。

真实 5 段先整理原视频、mask 和对齐回执；所有方法使用共同可见区域，报告手遮挡排除比例，并增加动态区域误差/轮廓或可信跟踪误差，避免静态背景撑高 PSNR。只用输入窗口拟合/预测，再在未来或新动作评估；已被拟合的同段只能称 reconstruction。没有真实独立 E/ν/ρ 测量，就做行为级定量和明确的有效引擎参数，不制造“真实参数准确率”。钱包和薄壁瓶不应被描述为已正确分解的均质材料。

### 8.1 资源不足时保留什么

最小包保留：P0 来源/配置核对；C/D 严格配对；全量散点与常数控制；原生成器至少一个材料响应与一个 drop 校验；PIXIE/VoMP 中确实可运行的独立 baseline，并如实披露覆盖不足。不能以“没时间”在回复中将未完成的关键比较说成已解决。

随后才是更多 seeds、G 控制、第二个外部方法、真实新动作。若连 C/D 和物理校验都做不完，应诚实地降低证据完备程度，优先修改不被支持的结论；加很多未经校验的新 demo 不会补上逻辑缺口。

工程上：先测一次 batch/epoch 的实际耗时，再安排并发；只在冻结 backbone、输入预处理和采样一致时复用特征缓存，缓存 key 含权重/代码/帧索引/预处理 hash。原模型需要 patch tokens 时不能用只有 pooled features 的 M2 缓存替代。缓存读写、decode、H2D 分别计时，配置和子模块冻结后再决定 BF16/worker/多卡。数值设置变更需短评估比对，避免“提速”改变目标。没有重新授权时这些 profiling 同样不在 A800 上执行。

### 8.2 明确的成败分支

| 结果 | 允许的论文结论 | 后续动作 |
|---|---|---|
| C/D 全量、多个 seed 上稳定改善，原仿真校验通过 | 在已验证材料、动作和观测设置内，场反馈带来额外收益 | 给效应大小与范围，避免扩展到任意真实物体 |
| 场预测好/推理依赖明显，但 C/D 无稳定改善 | 场提供可视化和辅助监督价值；独立反馈收益未建立 | 收缩桥接优越性，把反馈作为待验证设计；不拿 mask ablation 替代 |
| 只 E 或部分材料族改善，整体/尾部不改善 | 有条件、分参数的收益 | 同时报整体与负面结果；该切分若事后发现，标 exploratory |
| 原 MPM 某些范围校验失败 | 数据仅在通过区域支持定量推断，失败区域不可用于强物理主张 | 限制、修订/重发数据与后续 v2；不将新引擎结果洗成旧数据质量 |
| 真实 replay 好，但无独立材参 GT | 可拟合有效引擎行为 | 不宣称恢复真实材料唯一参数 |

## 9. 方法创新放在 rebuttal 后，避免分散核心证据

用户提出的四个方向仍值得推进，但不宜同时塞进这次 deadline：

1. **Qwen 材料语义＋动态证据数值头**：可研究语义先验如何被真实运动纠正；不是模型变大就能解决不可辨识。先冻结原稿实验，不把 Qwen 加入替换后的新主模型来掩盖旧 bridge 对照。
2. **共享响应表征＋few-shot 引擎适配**：[UniPixie](https://arxiv.org/html/2606.05399v2)已有多求解器概率预测与离线拟合先例，创新要落实为未见引擎支持集 K=0/1/5/10/20 的响应恢复与成本，且对象/动作隔离。G2 尚不支持该结论。
3. **中间物理量**：[Analytic Dynamics](https://arxiv.org/html/2608.31025v1)已有物理状态教师→视频学生蒸馏；其未见物体 jelly log E MAE 从无对齐 0.265 到完整 0.175，但不能据此假定本项目场反馈必有效。更值得验证“物理教师蒸馏、辅助监督、测试时反馈”三个机制的区别，以及遮挡/未见加载下的收益。
4. **在线拟合生产真实标签**：[PhysTwin](https://arxiv.org/html/2503.17973v1)、[EMPM](https://arxiv.org/html/2601.17251v1)可作为工具与比较来源。拟合标签应称指定引擎的有效参数，按跨动作、独立测量和多起点质量分级，不能当无误差真实 E。仅在独立动作 B 上仍有效，才把动作 A 拟合结果接入训练。

后续数据优先做同几何/外观、不同材参、已知加载的反事实配对，选择足够可见的主动形变区间，保留释放/恢复；再增加动作遮挡、非规则 GS/真实重建几何和多部件材料。把物理状态、SI 单位、相机、时间、接触、引擎配置与质量标记一起保存。短期补一个校准集比急加 10 万条新视频更可信，但不能倒过来把这个新集的收益归因到旧数据。

## 10. 回复写作框架

每位 reviewer 先承认其最关键的正确质疑，再给可核查的数值、控制差异、边界和复现入口。禁止只说 future work。下面是待填证据的结构，**不是可直接提交的已完成回复**：

- **a1nG**：区分参数中位数收益与均值尾部退化；给 C/D 全量散点、常数控制、族内相关与对象 CI。用真实结果回答是否学到连续参数；如果没有，明确收缩。
- **AKYF**：优先报告原 MPM 标准校验、drop 耗散与可靠范围；给独立方法的输入/预训练/适配条件；回答单独移除反馈；提供训练阶段数值表和真实行为证据。新引擎的漂亮结果不能替代旧模拟器验证。
- **Nxg5**：明确 Eq.19–21 不是普适机械约束；指出实际聚合轴和运行启用状态，给移除正则结果或纠正未使用的表述；将 field-quality / inference-dependence / retrained-benefit 三种证据分开；补 VLM 及所有消融的配置差异。

封版时每个数字都应能追到样本清单、指标脚本和检查点；每个“改善”都有明确比较对象；每个“物理正确”都有相应验证范围。不预承诺 reviewer 一定改分。
