# G1c 完成反馈与 G1d 定向对照

本轮结论：局部时序残差分支没有证明场的独有收益，不能据此启动全量训练。G1d 只检验一个具体问题：移除修正头直接读取 RGB 的通路后，场桥是否仍被忽略。所有结果均来自开发验证集，测试集未使用。

## G1d 最终反馈

四组均已在第 8 轮因验证停滞结束，[最终记录](G1D_FINAL_RESULTS.json)如下：

| 方法 | 最佳标准化参数 MAE ↓ | 选中轮次 |
|---|---:|---:|
| 冻结 RGB 起点 | 0.799952 | 0 |
| D 预测场桥 | 0.798423 | 7 |
| G 等容量特征桥 | 0.798270 | 7 |
| O 真场桥，特权诊断 | 0.798416 | 7 |
| S 置乱真场，特权诊断 | 0.798415 | 7 |

D 相对 RGB 仅约 0.19% 改善，且略差于 G；O/S 仍无有用差异。移除显式 RGB 通路不足以恢复场依赖。[G1d FP32 扰动](G1D_D_BRIDGE_SENSITIVITY_FP32.json)中，清空桥输入的平均参数变化仍仅 1.53e-8，最大 2.38e-7，时间反转均值 1.95e-9。桥内偏置、位置编码、RGB 查询及近似常量残差仍可绕过场内容；不能再把直接 RGB 输入认定为唯一原因。

本阶段未通过 2% 路由阈值，旧全量训练继续暂缓；GPU 训练进程均已退出。下一阶段优先采用下文的目标审计与相同外观/不同材料成对协议，修正桥的常量捷径后再安排训练。网页暂停与继续的实际回执见 [G1d 控制验证](G1D_WEB_CONTROL_VERIFICATION.json)：暂停退出旧 PID，随后新 PID 从 320 步恢复至 360 步，并正常到达早停结束。

## G1c 实测结果

512 个训练样本、128 个验证样本，按物体隔离，seed 17。六组均从同一冻结 RGB 检查点开始；第 0 轮可保留原估计器。记录见 [完成快照](G1C_FINAL_RESULTS.json)。

| 方法 | 最佳标准化参数 MAE ↓ | 选中轮次 |
|---|---:|---:|
| 冻结 RGB / C | 0.799952 | 0 |
| D 预测场局部时序桥 | 0.793609 | 3 |
| G 等容量特征桥 | 0.793628 | 3 |
| D 截断场反馈梯度 | 0.793596 | 3 |
| O 真场桥，特权诊断 | 0.793571 | 3 |
| S 跨物体置乱真场，特权诊断 | 0.793576 | 3 |

六组材质实验均在第 8 轮因验证停滞结束。D 相对 RGB 仅改善约 0.79%，与 G 的差距约 0.000019；真场与置乱真场几乎相同。未通过预设的 D 同时超越 RGB/C/G 至少 2% 的路由阈值，不能将微小的共同改善归因为正确物理场信息。

独立的 64 条训练样本 field_fit 在 112 次更新后停止。最佳训练编码场 MAE 从 0.48053 降至 0.11302；最终轮为 0.13671，接触 IoU 只有 4.81%，召回 99.86%。这说明预测器能降低编码误差，但接触预测存在大量误报，尚未充分拟合。这些是训练指标，不能作为验证泛化或物理标定结果。

## 同检查点场桥扰动

保持 RGB、权重和 128 个验证样本不变，只干预进入 field_encoder 第一层的桥张量。分别清零、反转时间，记录参数输出变化；这只是分支依赖检查，干预分布外，不能作物理因果结论。

- BF16：清零桥张量的平均参数变化约 1.77e-6；时间反转未见变化。
- FP32 复核：清零变化均值 8.39e-9、最大 1.19e-7；时间反转均值 1.97e-9。原参数 MAE 0.793644，清零后仍为 0.793644。
- 结论：这个检查点的材料输出几乎不依赖桥输入；BF16 舍入不能解释该现象。最可能的工程问题之一是修正头绕过桥，直接利用 RGB 向量；位置编码、偏置和常量修正也需要排查。

审计原始记录：[BF16](G1C_D_BRIDGE_SENSITIVITY.json)、[FP32](G1C_D_BRIDGE_SENSITIVITY_FP32.json)。缓存特征本身仍为 BF16；FP32 指本次审计的模型计算精度。

## G1d 的唯一架构变化

配置 `model.residual_rgb_input=false`，将残差头输入中直接拼接的 pooled RGB 向量置零，保留其维度和参数量。RGB 仍参与场预测及局部注意力查询；不能把 G1d 描述为完全无 RGB 的场估计器。

四组 D/G/O/S 与 G1c 使用相同冻结 RGB 起点、512/128 数据、seed、局部模块、场监督、优化器和最多 24 轮预算。每组前 2 轮场预热，联合阶段至少观察 6 轮，连续 4 轮未达到 0.2% 相对改善则早停。两组真场输入仅限特权诊断。原 RGB 和 G1c 的冻结 C 输出一致，可复用作基线，不另做无信息的重复训练。

反馈节点：

1. 初始化：四组第 0 轮 MAE 均需等于原 RGB 的 0.7999518818682233，已核验。
2. 首次完整检查点：网页实测暂停 D，进程退出、保存约 29 MB 完整检查点；恢复使用新 PID，优化步从 320 增至 360，已核验。完整回执见 G1d 网页控制验证记录。
3. 结束：生成 `docs/G1D_RESULTS.json`，比较 D/G 及 O/S。若仍失败，先检查桥有效变化量、常量/偏置捷径和监督目标可辨识性，停止堆叠更大骨干或全量预算。
4. 若有候选通过路由阈值，再做独立种子和按物体配对统计；冻结方案后才评估测试集、真实视频及在线拟合参照。

## 工程修复与验证

- 新架构放在 local_model.py，历史 model.py 保持字节不变，避免旧检查点和冻结骨干缓存失效；骨干缓存命中不等于训练所有模块被冻结。
- 统一训练、评估、场审计、性能测量入口的模型工厂，避免用旧模型类加载新架构检查点。
- 第 0 轮保存完整回退检查点，记录冻结 RGB 起点 SHA256；恢复时清空初始化选项，避免初始化与 resume 冲突。
- 局部时间卷积前屏蔽填充帧，安全处理整个视角都被填充的注意力；保持视角置换不变性。
- 场拟合检查只取训练样本，独立记录训练范围；GT 字段仍由部署模型拒绝。
- A800 完整 28 项测试通过，另有真实双 GPU 训练/128 条无重复验证预检。包括冻结权重、零修正一致性、梯度到达场分支、无效帧/视角不变性、等容量控制、检查点恢复、回退不算改善，以及 G1d 直接 RGB 输入置零。
- 本轮继续复用 SHA256 验证过的本地特征缓存和 BF16。历史 G1b 同轨迹训练中位轮时约 31.54→17.97 秒；不能将小样本读取或验证加速当作完整训练的加速比。

## 后续优先顺序

若 G1d 未通过，优先做训练目标与观测可辨识性审计：可视化逐帧接触、流和应力目标及有效掩码，量化前景/背景比例、逐样本场变化和参数相关性；针对稀疏接触修正损失权重与采样，避免只提高召回却扩大误报。再用引擎重放生成单位、边界条件和动作已知的响应，用相同几何/外观、不同材料的成对样本检验场桥必要性。

旧数据是视觉编码场，不能当作 SI 度量场；当前也没有实际接入引擎做材料标定。获得尺度、载荷和边界条件后，才适合比较短视频预测与在线拟合的误差/耗时，并把静态先验和外部真实数据纳入匹配对照。G1–G1d 在同一验证集上迭代，只能支持开发决策。

## 运行

```bash

python scripts/setup_g1d.py --register
# 配置需由唯一队列管理器重载；文件锁阻止重复实例。

# 独立启动一组：
python -m fieldbridge.train --config configs/g1d_D_local_fields_seed17.json

# 对同检查点做 FP32 桥依赖审计：
python scripts/audit_bridge_sensitivity.py \
  --config configs/g1d_D_local_fields_seed17.json \
  --checkpoint runs/g1d_D_local_fields_seed17/best_material.pt \
  --output runs/g1d_D_local_fields_seed17/bridge_audit_fp32.json --fp32
```
