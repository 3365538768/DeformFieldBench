# 共享材质响应与引擎适配：受控试验

## 为什么先做这一步

同名的参数不是跨引擎 GT。共享表征学习可观测的受控力学响应；每个已标定引擎保留自己的本构、版本、系数定义、单位和训练集归一化。引擎 ID 只选原生输出头，不进入共享响应头。未知引擎不能直接使用现有头。

这一步检验适配训练是否跑通、有无负迁移，尚不是从视频恢复参数，也不是 bridge 优于无 bridge 的证据。静态已知载荷只监督弹性系数，不估计密度。两边的小形变对应关系不能外推至大形变、接触和混合材料。

## 实际求解与预设门槛

- NVIDIA Warp FEM 1.11.1：三维 P1 四面体线性弹性，原生 `mu, lambda_lame`，FP32 几何/场装配与 CG。记录重新计算的 `||Ax-b||/||b||`，不只信 CG 递推残差。
- libuipc / pyuipc 0.0.29：实际 CUDA SNK1，显式实验系数 `mu=mu_Lame, lambda_snk1=lambda_Lame+mu_Lame`，固定密度 1000 kg/m³；隐式动力学收敛后读取稳态。
- 共同 SI 长方体、正体积共形四面体、x=0 完全夹持、末端均布表面力。按每个表面三角形面积/3 给 UIPC 节点分配载荷，与 Warp 面积分一致。
- 求解健康：固定点误差 <1e-9 m，J>0.95，位移梯度范数 <0.02，合力误差 <1e-5，速度 <1e-6 m/s，末 20 帧变化 <位移的 0.1%，Warp 真实相对残差 <0.1%。
- 首轮 5 配置 × 2 引擎：8×4×4 到 16×8×8，E 翻倍，轴向/横向力，dt 减半并保持模拟时长。完整场跨引擎差 <2%，网格响应变化 <15%，E 反比误差及时间步变化 <1%。门槛在首次执行前写入脚本，未按结果修改。

首轮 5 项通过；完整场最大差 0.02433%，网格变化 14.48%。**该网格精度只够验证一致离散夹具上的适配方案**，不能称为高精度物理数据。后续用于视频训练/论文主结果前须进一步收敛至更严格网格误差，并增加接触、大形变和真实物体几何。

## 响应矩阵与训练控制

6 个长方体夹具、E=12/24/48 kPa、ν=0.2/0.3/0.4、X/Y/Z 三种已知末端力、2 个引擎，共 324 个案例。前 4 个夹具训练，后 2 个验证；同一夹具的材料、引擎、动作全部属于同一 split。材料网格在训练/验证中相同，当前只测新几何泛化，不宣称未见材质泛化。每一个生成案例重做健康检查，每一对完整位移场也须差 <2%。

输入：X/Y 载荷下完整节点位移场及已知几何尺寸。共享目标：未作为输入的 Z 载荷末端响应，取匹配 Warp 小形变参考；只在训练集监督。各引擎分别回归原生系数。原生参数不做跨引擎简单平均。归一化统计全部只拟合训练集。

固定 17/29/43 三种子，三个模型使用相同编码器、输出头、初始随机数与预算：

1. `native_only`：共享编码器 + 原生参数头，仅参数监督。
2. `response_aux`：加共享、未见载荷响应辅助监督（权重 0.1）。
3. `paired_alignment`：再加严格匹配训练对的表征一致性（权重 0.1）。

最多 700 轮；验证 MAE 连续 80 轮无 1e-4 的改善则停止，最少 80 轮。相同准则选择检查点。验证集兼用于选择，不能当最终测试。输出每引擎原生参数 MAPE、标准化 MAE、共享响应米制误差及三种子结果。任何失败门槛阻止进入下一阶段。

## 接下来与公平比较

先比较参数头预测经各自求解器回放后的新动作场误差，再做从 RGB 预测度量位移/接触场的学生模型。最终和在线拟合方法共享视频、几何/尺度/载荷信息、动作划分及求解预算；分别报告参数误差、未见动作回放误差、单视频推断/拟合 GPU 时间与离线训练成本。不能只比较不同引擎标签 MAE。

本阶段的两个本构已有解析的小形变系数换算。因此还需解析换算/经典逆 FEM 作为控制；学出的适配效果不能据此宣称超越已有在线优化。真正的广泛引擎适配需覆盖不同本构、动作和物体，并验证不可辨识情况及置信区间。

## 运行和控制

隔离安装 `.engine-envs/warp`（`warp-lang==1.11.1`）与 `.engine-envs/uipc`（`pyuipc==0.0.29`），主训练环境安装本项目。固定 Warp 版本是因为当前服务器驱动为 CUDA 12.8，最新版 wheel 要求 CUDA 13。

```bash
.venv/bin/python scripts/setup_g2.py --register
.venv/bin/python scripts/optimization_manager.py
```

队列在 G1f 完成后自动启动 G2，web 支持暂停/继续。暂停在完整案例或训练 epoch 边界生效；当前过程保留状态等待继续。案例按配置和求解源码 SHA 缓存，重启可跳过完成案例。训练进程内暂停保留优化器状态；进程崩溃后从固定种子重新训练当前小型控制，不声称崩溃续训。

官方来源：[Warp FEM](https://github.com/NVIDIA/warp/tree/v1.11.1/warp/examples/fem)、[兼容驱动说明](https://github.com/NVIDIA/warp/blob/v1.11.1/README.md)、[libuipc SNK1 定义](https://github.com/spiriMirror/libuipc/blob/main/docs/specification/constitutions/stable_neo_hookean.md)。

## 已完成适配诊断与可视化

324 个案例已完成并通过数值/配对检查；72 个训练输入、36 个验证输入，均来自完整观测 X/Y 位移场。9 组训练均完成。三种子平均验证 MAE：native_only 0.036906±0.004590、response_aux 0.036490±0.006374、paired_alignment 0.036421±0.006446。差距小于种子波动，不判定共享/对齐已有可靠优势。详见 `G2_ADAPTER_RESULTS.json`。下一项 `G2r` 对 seed17 的 36 个验证输入，把三种预测、训练均值、经典线性逆 FEM 参数分别带入原引擎回放未见 Z 载荷，共 180 次求解。经典参考同样获得完整节点观测与已知几何载荷，不代表现有论文的 RGB 在线拟合表现。

网页新增双引擎三维预览，可选择 324 个案例、旋转/缩放、查看位移色标、原始轮廓及形变放大倍数。libuipc 播放实际保存的轨迹采样帧（含初始帧共 26 帧），Warp 只有静态解。未来生成时成功案例逐个登记，可提前观察，但明确标记配对验收尚未完成。读取接口只接受 manifest / 生成索引登记的案例 ID，不接受任意路径。

### 未见动作的实际回放结果（seed17）

180 次 Z 向载荷求解全部完成，平均完整位移场相对 L2 误差如下。每种方法、每个引擎 18 个验证组，整组几何隔离。

| 方法 | Warp | libuipc |
|---|---:|---:|
| native_only | 1.9054% | 1.7937% |
| response_aux | 1.5505% | 1.1601% |
| paired_alignment | 1.5275% | 1.1383% |
| 训练均值 | 52.3911% | 51.7439% |
| 经典线性逆 FEM | 0.00732% | 0.03433% |

共享响应辅助在这个 seed 的回放误差上有改善，但三个种子的参数 MAE 仍不足以宣称稳定优势。经典方法更优，说明完整无噪声场 + 已知网格/载荷 + 小形变线性近似是容易被物理求逆解决的受控问题。当前学习模型尚未达到这个参考精度。不能用这批结果宣称接近真实视频上的在线拟合工作。原始结果：`G2_ENGINE_REPLAY.json`。

下一步 G3v 已启动：真实 UIPC 载荷从 0.0002–0.05 N，E=12/48 kPa、两种网格共 20 个求解，检查理想相机 224px、80mm 视野下 XY 投影位移是否至少 2px，同时检查数值健康、稳态和网格敏感性。仅估算可观测性，不把网页形变放大当作视频信号；大形变不要求与线性 Warp 等价。

### 视频可观测性审计已完成

20 次实际求解完成：原始 0.0002 N 在 E=12/48 kPa 的细网格理想运动仅 0.0855/0.0214 px，不宜直接作为 RGB 训练信号。0.02 N 分别为 8.56/2.14 px；0.05 N 为 21.23/5.35 px。10 个载荷/刚度组中 5 组通过 2–30px 与 <15% 网格变化的候选筛查，仍需更严格网格收敛再生成正式训练集。原始证据 `G3_FORCE_VISIBILITY.json`。网页数据阶段可切换 G3v 观察这些实际轨迹；该阶段只有 UIPC，不伪造另一引擎的等价结果。
