## 1. 锁定范围

核心交付仅包括：

1. 原论文关键数字、检查点、实际训练配置与 split 的对应核实；VLM 与每阶段训练的复现说明。
2. 原模型的严格 C/D 重训对照，另保留 B 以区分系统收益与反馈收益。C 保留 bottleneck、场预测与场监督；D 加预测场反馈；B 是明确披露设置的直接回归控制。全量散点、常数控制、尾部、按对象统计和 replay 共同报告。
3. 原生成器的代表性物理校验和 consistency 正则适用性/真实启用状态；承认不适用范围。
4. 能实际运行的独立公开 baseline 与公平输入/预算说明；三位 reviewer 逐项回复稿和必要的真实行为证据。

更多新数据集、大规模引擎生成、Qwen 全面微调及额外 demo 不再作为 V1 deadline 前的扩展任务。失败的核心对照不通过追加弱 baseline、挑参数或挑对象来“补成正结果”。

## 2. 证据状态不能混淆

- **当前状态：尚未证明独立反馈收益。** M2 的 C=0.68281、D=0.68672，D 误差约高 0.57%；G1F 预测场与普通特征桥近似。它们是重构后的小规模单种子诊断，足以阻止继续默认桥接有效，但不足以证明原模型或所有场方法无效。
- **反馈不成立，不等于整个系统不成立。** D 不优于 C，只能限制反馈主张；如果 C 明显优于 B，辅助场监督仍可能值得保留。
- **统计不显著，不等于证明零效应。** 置信区间很宽时应报告证据不足，不把它包装成“已经证伪”。
- **正结果也不能绕过数据问题。** 原生成器可信度不合格，不能仅凭同生成器 replay 优势宣称真实物理有效。

## 3. 决策规则：预先登记，不看测试后修改

选择全部样本、按对象宏平均的主要参数误差，记录 lower-is-better、变换、缺失维度处理和 train-only 归一化。将相对改善定义为 `(control_error − candidate_error)/control_error`，正值表示改善。

主表给 B/C/D 各 seed 的结果；至少 3 个独立训练 seeds 作为计划目标，保留每个对象的配对误差。对象 bootstrap 反映对象不确定性，种子重复反映训练不确定性，二者都要报告，不把 seed×object 全当独立样本。对象/种子数量不足或区间不稳定时明确降级为 preliminary。

将项目既有 **2% 相对误差改善**作为“值得继续为反馈投入”的实际意义门槛，不称为普适物理阈值。主指标、阈值和协议应在本轮正式测试前冻结；既有探索性结果已经看过，不能声称整个研究从未接触过任何测试结果。

| 证据 | 结论与动作 |
|---|---|
| D 对 C 有稳定改善，配对区间支持正收益，实际效应达到预设门槛，尾部与行为无实质退化 | 保留桥接主张，但限定数据、材料和动作范围；完成核心 rebuttal，不扩大 V1 任务 |
| D−C 接近零且区间仍宽，或不同 seed 反向 | 证据不足；按预算上限停止 V1 扩展，立即反馈“不支持可靠收益，尚未证明无效”，不再无限加 seed/调参 |
| 严格多 seed 比较中，相对改善的 95% CI 上界低于 2%，且配置/训练/数据审核合格 | 在该预设指标与协议内排除达到 2% 的实际收益；立即反馈并停止为 V1 反馈组件继续优化，开始 V2 |
| D 明确劣于 C；或 B/C/D 均无法优于训练集常数/类别先验，并排除代码、预算和数据划分错误 | 直接报告相应负结果和证据范围，转向 V2；不把失败描述成“仅需更大 backbone” |
| 参数误差无优势但未见动作响应有稳定优势 | 不能称系统完全无收益；如实定位为行为拟合收益，说明是否满足论文任务，不用它掩盖参数推断不足 |
| 原数据校验失败，或关键原稿产物不能恢复 | 不伪造原稿复现；报告阻碍与已知事实，修正原稿范围。V2 从校准数据/协议重建；这本身不能证明架构在可靠数据上无效 |

“排除 2% 改善”只适用于选定任务与总体，不等于证明所有未来数据、物理量或模型均不可能受益。若对象级置信区间仍不稳定，不据单个窄区间宣布严格等效。

触发后**先在当前对话立即说明**比较对象、主指标、效应/区间、种子、是否原模型、物理校验状态和具体停止项，再开始 V2 的本地构建。通知不等待新方法训练完。没有创建每小时任务、后台通知或恢复自动调度。

## 4. V2 起步：保留目标，替换未经证实的机制

V2 的问题定义：从给定可观测条件的视频，估计可迁移的材料响应及不确定性，再经少量标定映射到指定引擎的有效参数；在未参与拟合的动作上验证。未知力、尺度和内部结构造成的歧义要显式保留。

触发后第一个开发里程碑是独立、可复现的小闭环，不直接启动大规模生成：

1. 版本化保存 V1 代码、配置、split、检查点与失败证据；V2 使用独立配置命名空间、数据 manifest 和输出目录，禁止覆盖 V1 rebuttal 产物。
2. 建立校准的同几何/外观、不同材料、不同加载配对小集，保存实际时间、尺度、载荷/边界、引擎与质量标记；保留释放恢复，减少无信息静止尾帧。先解决可辨识性，再扩大物体复杂度、遮挡和复合材料。
3. 默认以强时序视频编码器加连续数值头为基础。物理教师中间状态优先用于训练期监督/蒸馏；测试时不强制预测 dense stress 再反馈。保留纯视频、辅助监督、普通特征蒸馏与物理教师蒸馏控制。
4. 接入共享标准响应表征和独立 engine adapter；原生参数、单位、本构、数值配置单独保存。不同引擎同名 E 不自动视为相同标签；跨引擎用校准响应与留出动作评价。
5. 真实拟合教师产出的是带来源和质量标记的有效参数，不是实验室材参真值。以动作 A 拟合、B 验收，测试物体不得进入训练标签库。
6. Qwen 先作为可移除的语义先验/特征对照，通过同外观不同力学响应与反语义样本验证其作用；没有超过强视频控制就不纳入核心结构。

V2 的第一验收点：数据有足够运动可见性、标准夹具可辨识、纯视频优于常数控制、教师/辅助路线在对象隔离验证中有可信收益，再考虑 few-shot 新引擎与真实迁移。工程软件跑通不计作科研可行性证明。
