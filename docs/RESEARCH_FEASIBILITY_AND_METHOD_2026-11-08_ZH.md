## 1. 结论：受限目标可做，任意视频唯一恢复全部真实参数不可保证

建议将论文目标定义为：

> 从一个静态或交互视频，摊销估计观测支持的材料响应分布；在指定且经过标定的引擎中输出有效参数、适用条件与近似误差。在未见物体和未见受力条件下，以远低于逐物体优化的测试成本，接近在线拟合的响应预测质量。

“接近”必须通过下面的同输入、同动作、同算力质量—时间曲线检验，不能由参数 MAE 或好看的重建视频代替。

| 目标层级 | 判断 | 必要条件 / 输出边界 |
|---|---|---|
| 静态图像给材料类别、软硬先验与 plausible 参数范围 | 可实现，已有工作支持 | 外观不能唯一决定内部结构和机械参数；属于先验 |
| 有形变的视频，在有限材料模型中预测引擎有效参数 | 值得推进，已有直接相关证据 | 需要足够激励、时间信息、几何尺度或明确的尺度不确定性 |
| 在未见动作下接近逐物体拟合 | 合理但尚未由本项目证明 | 材料、外力、几何混淆需要受控；在线拟合本身也不是物理真值 |
| 同一材料表征迁移到已标定的多个引擎 | 有条件可实现 | 只比较共同可表达的响应；不同离散化、本构、接触的误差要显式输出 |
| 任意静态视频恢复唯一的 E、ν、ρ、屈服应力，直接适用于任意引擎 | 不成立为普遍保证 | 缺失加载、尺度、内部结构或未发生屈服时存在不可辨识性；有些引擎无法表达目标行为 |

这里的不可辨识性不是模型不够大。例如，在同一线性弹性几何和边界下，静态已知力满足位移随 F/E 变化；仅施加规定的位移而不测反力时，整体缩放 E 不改变静态形状。没有独立质量或力标定时，某些条件下同时缩放 E、ρ、外力会保持运动相同。静态视频不包含惯性响应；没有进入屈服区的视频不能凭动态证据确定屈服应力。本项目 I1 夹具已实测其中的特例，不能靠更多同类样本消除这样的对称性。

因此，静态输入返回“先验范围”，交互输入返回“被该交互更新后的分布”；两者均可使用，但可信程度和物理含义不同。材料真参数、对象有效刚度和特定引擎拟合参数也必须分别命名。

| N0/N1 后验分支没有接受不确定性训练 | 其区间只属于软件输出 | 不能凭更宽区间获得较高覆盖就宣称概率方法有效 |
| 多轮桥接与等容量/辅助监督控制未获得稳定独有收益 | 暂无理由将场桥作为必定成功的主线 | 不能用跨骨干、跨取样或跨视角数的最好数字做因果结论 |

| 线性 FEM/Warp 小应变位移相对差约 1.59e-6 | 一个受控线性夹具的一致性通过 | 不代表原 MPM、复杂接触、混合材料已经标定 |
| 视频解码到材参 JSON 已打通 | 推理入口、时间戳支持、冻结特征前向已核验 | 不是现实世界效果证明，启动总耗时也不是纯前向速度 |

N0–N2 使用 512 条训练、128 条验证、88/10 个物体、单视角 16 帧、冻结 DINOv3-L/16、相同的 2,128,179 个可训练参数、seed 17。物体聚类 bootstrap 的方法差异区间跨 0，属于探索性筛查；最终测试未使用。历史最强单视频控制与严格 NF 模型目标、容量或取样不同，不能拼表宣布胜负。

当前 4,914 条有效原始包 / 108 个物体足以做管线验证、协议审计和有限域基线，尚不足以支持任意真实交互和混合材料。主要限制是加载可观测性、真实局部应变、几何/材料/动作的受控重复，以及标签物理含义，而非单看条数。旧 RGB 应力可视化不能当 SI 应力；缺失标签应继续 mask。GS 外观完整也不等于体积、厚度与内部结构被测准。

也重新核对了[原论文](https://arxiv.org/html/2610.17591v1)的论证边界：表 5 完整模型的未过滤 SPE 中位数为 0.299，去 field auxiliary 为 0.312；但未过滤参数 Mean MAE 最好的是去多阶段训练 1.118，完整模型为 1.139。论文已承认指标间有权衡。该消融移除了场辅助学习，并未单独证明“显式场反馈优于相同辅助监督、容量和输入下的非场反馈”。逐方法去掉最高 SPE 的 20% 样本也改变了被评估集合，后续不应以过滤分数作为首要结论。新方案应补上这类匹配控制与未见干预响应证据，而非只更换一个更容易获胜的指标。

## 3. 现有方法详细对照：哪些能力已有，缺口在哪里

以下数字均是**各论文自身协议的报告结果**，跨行不能直接排名。CD 的归一化、测试物体、输入模态和时间边界不同。预印本和刚发布的工作也不代表结果已独立复现。

### 3.1 逐场景拟合：质量上界需要比较，但并非真实材参保证

**PhysTwin** 使用稀疏多视角 RGB-D、三维追踪和操作者控制点；CMA-ES 搜索拓扑及全局参数，再优化局部弹簧/接触。其 22 个交互场景采用前 70% 重建、后 30% 预测；主表未来 CD 0.012、Track 0.022，另有新交互实验。官方仓库给出的毛绒物体示例约需 CMA-ES 12 分钟、梯度阶段 5 分钟，这不是所有预处理均计入的统一端到端时间。其弹簧刚度也不能直接等同材料杨氏模量。[全文](https://arxiv.org/html/2503.17973v1)、[官方代码](https://github.com/Jianghanxiao/PhysTwin)。

**NeuSpring** 在拓扑与局部刚度上做结构化改进，仍需逐场景拟合。相同系列场景的未来 CD 从 PhysTwin 的 0.012 降至 0.009，Track 从 0.022 降至 0.017。它说明更合适的结构与正则化确实重要，没有证明材料参数可由任意单视频唯一恢复。[全文](https://arxiv.org/html/2511.08310v1)。

**EMPM** 使用多视角 RGB-D 与三维追踪、可微 MPM，包含弹性和弹塑性。弹性距离仅从 PhysTwin 的 0.0227 改善到 0.0222，而弹塑性从 0.0177 到 0.0082，说明**本构模型是否能表示行为**可能比网络模块更关键。其表中训练约 161.80/171.60 秒，对照 PhysTwin 496.84/589.51 秒；作者明确对照只统计 PhysTwin 梯度阶段，不含 CMA-ES。在线更新展示仅有绳子、面团两个对象，不能外推任意材料实时准确。长时间遮挡还会使可靠追踪流失。[全文](https://arxiv.org/html/2601.17251v1)、[官方代码](https://github.com/rai-opensource/empm)。

**PhysReal** 进一步使用局部材料 patch、解析本构专家和神经残差，处理真实单视角 RGB-D 与接触，仍进行渐进式逐物体优化。其两个数据协议下的未来 CD 分别为 0.015 和 0.012，对应 PhysTwin 为 0.017 和 0.030；第一协议 Track 同为 0.027，并非全面大幅提升。“空间混合材料＋神经本构残差”已经有直接工作，不能单独作为我们的创新。还要警惕残差将加载或几何错误吸收后，图像拟合很好但材料错误。[全文](https://arxiv.org/html/2609.07532v1)、[项目](https://physreal.github.io/anonymous_web/)。

### 3.2 快速推断与先验：最接近我们目标的工作

**ReconPhys** 是必须加入的新基线：单目视频前馈预测质量、刚度、阻尼、摩擦，同时重建 3DGS，训练阶段使用可微仿真—渲染回路。主要定量环境是合成自由落体与地面碰撞：496 个资产，450 训练、46 测试，输入 20 帧，预测后续 10 帧。报告未来 PSNR 21.64 对 Spring-Gaus 13.27、CD 0.004 对 0.349、推断小于 1 秒；官方已列出代码、检查点与数据。

但这些数字不代表已经解决复杂真实戳压：训练动作族受限，真实视频主要是定性展示；文中基线输入 4 视角而本方法 1 视角，原表不是我们需要的严格同输入比较。质量等参数均属于其弹簧表示，不是直接获得 E/ν/ρ。我们的“单视频无在线优化”本身已不能作为新贡献。[全文](https://arxiv.org/html/2604.07882v1)、[代码及权重/数据入口](https://github.com/chuanshuogushi/ReconPhys)。

**MatPhys** 主张静态材料先验、部件建模、共享材料 codebook 与视频编码，前馈估计局部刚度等。其主表未来 CD 0.008，对照 PhysTwin 0.012、NeuSpring 0.009；codebook 消融由 0.012 改善到 0.008。但需要明确复现边界：截至本次读取，官方 README 的最终训练 recipe 明写 `per-case fitting with smooth/damp regularizer`；论文中的零样本比较还使用同类别其他案例优化参数的均值。公开前馈检查点、论文声明、逐案例训练 recipe 应分别核对，不能直接把所有数字当作严格未见物体、零测试优化基线。这里存在待澄清的协议差异，并不据此判断论文结果无效。[全文](https://arxiv.org/html/2605.19386v1)、[官方说明](https://github.com/Yrainy0615/MatPhys)。

**EgoPhys** 从自我中心单目视频构建追踪与单目三维观测，仍先做逐序列 CMA-ES，再用共享、受限的拉伸/压缩 codebook 代替密集局部优化。19 条序列中 8 条训练 codebook、11 条留出；部分物体名在两组出现，不能把所有留出序列都视为未见物体实例。留出表 CD 0.0319 对适配后的 PhysTwin 0.0457。其 1.36 分钟对 14.26–80.43 分钟是 anchor 确定后的阶段耗时，不含粗搜索与前处理。它支持“可复用先验减少优化”的路线，也明确限制了“完全不需要逐对象辨识”的宣传。[全文](https://arxiv.org/html/2606.16202v1)、[项目及当前开放状态](https://hjhyunjinkim.github.io/EgoPhys/)。

### 3.3 静态材料与跨引擎：创新定位最重要的先例

**PIXIE** 基于三维资产和多视角语义特征预测材料类别及 E/ν/ρ。训练资产约 1,624 个，标签包含 VLM 提议范围、人工整理和仿真检查，不是每个对象均有独立力学测量。适合当外观材料先验，不应将全部标签混入“物理实测 GT”。本项目首帧 DINO＋ridge 的失败，也不能否定这种训练量与表征更强的先验。[全文](https://arxiv.org/html/2508.17437v2)、[代码](https://github.com/vlongle/pixie)。

**VoMP** 从可渲染、可体素化的三维资产预测体积机械属性；MatVAE 利用材料属性数据库约束 E/ν/ρ 的关联，支持多种下游求解器。它说明物理有效的材料流形优于随意独立抽参数；但对象标签仍需区分数据库材料值、分割映射、VLM 推断与直接测量。部分 vegetation 数据不公开，公平对比必须使用公开子集，不能照搬私有全量指标。E 采用相同单位也不意味着网格、体积、接触和离散化误差自动一致。[全文](https://arxiv.org/html/2510.22975v2)、[官方代码与数据](https://github.com/nv-tlabs/VoMP)。

**UniPixie 是对当前构想最直接的创新重叠。** 它已经具有：共享、求解器无关编码；MPM/LBS/Spring-Mass 输出；条件 flow matching；材料软硬范围；通过参考仿真离线拟合其他求解器，再摊销输出。数据 PixieMultiVerse 约 1,410 资产，MPM 定量测试 41 对象，另外两类求解器测试仅 10 个弹性对象。主表 log E MSE 0.0091 对重训 PIXIE 0.0205，但材料分类准确率 93.9% 对 97.3%，运行 12.16 秒对 0.137 秒，存在权衡。

因此，“共享材质理解＋引擎 adapter＋概率头＋离线仿真蒸馏”这四件事的组合本身不足以构成清晰新贡献。它的概率范围主要描述合理软硬谱，尚不等于**给定实际交互视频、边缘化未知加载与几何后的校准后验**。跨引擎表中的中等刚度 LBS PSNR 36.81 对完整拟合 36.94，也不能说所有条件已超过优化。项目页当前标注代码/数据 Coming Soon；现阶段可以对照论文协议，不能把尚未发布资源写为已接入。[全文](https://arxiv.org/html/2606.05399v2)、[官方项目](https://unipixie.github.io/)。

### 3.4 其他启发与不应重复的方向

- **PhysWorld** 已使用真实视频拟合 MPM、合成多动作演示、蒸馏 GNN。其 799 FPS 对 3 FPS 是代理动力学 rollout，而不是端到端材参推断速度；说明离线教师有价值，也说明蒸馏本身不是新点。[全文](https://arxiv.org/html/2510.21447v1)。
- **NCLaw** 已研究保留 PDE 结构、学习满足结构约束的神经本构并迁移到新几何/边界。神经本构可作为后期模型失配补偿，但不应冒充新概念或让自由运动残差吞掉辨识问题。[全文](https://arxiv.org/html/2304.14369v2)。
- **GPWM** 是大规模粒子运动世界模型，覆盖多种物理域。运动预测能力不等于材料可辨识性；其数据规模达千万帧级，不宜直接作为当前小数据项目的从头训练方案。[全文](https://arxiv.org/html/2611.08338v1)。
- **Structure from Collision** 研究由碰撞判断内部结构，提示“空心/厚度不同”和“材料更软”容易混淆，应该进入硬负样本与不确定性定义。[全文](https://arxiv.org/html/2611.07900v1)。
- **Numerical Reliability** 在两套 Taichi MPM 操作场景中展示并行归约、长时间反传和有限差分的数值陷阱。结论只适用于其测试实现，不能概括所有引擎梯度都错误。我们的教师应先检查重复前向噪声、短/长时域梯度和离散收敛，再决定用梯度还是多起点无梯度搜索。[全文](https://arxiv.org/html/2609.34666v1)。
- 主动物理探测也已有 **Asking the World** 等工作；“再戳一下”不是独立创新，需要证明具体的材料不确定性减少和额外交互成本。[全文](https://arxiv.org/html/2609.39135v2)。

## 4. 建议的核心方法：基于可辨识响应的跨引擎摊销系统辨识

工作名称仅用于讨论，不作“首创”声明。建议主要贡献集中在**观测等价类—干预响应后验—引擎近似误差**的一致建模，优先采用独立无场路线。桥接保留为经过匹配的比较分支，其成功不是新方案成立的前提。

### 4.1 先定义共享的是什么，避免共享 latent 没有物理含义

将未知因素分开：

- `z`：在声明的材料族中，标准试样受规定应变/应力、卸载、松弛和剪切探测时的响应表征；另包含有证据支持的密度/质量信息。
- `η`：对象几何、尺度、厚度、内部结构、加载、接触、相机等干扰因素。
- `c_e`：引擎版本、单位、网格/粒子分辨率、时间步、积分和接触设置。
- `θ_e`：引擎可执行参数；不能自动将其命名为真实材料参数。

有限探测得到的是特定探测族下的材料等价类，不可能保证刻画所有未知本构。若对象是复合材料，先定义组分与界面，再将 `z` 升为少量部件表征；对象整体 N/m 刚度不能未经几何校正直接作为 Pa 单位的材料模量。

建议先做匹配本构的弹性 FEM/MPM；再扩展黏弹性、塑性和 2–4 部件。弹簧、LBS 可列为任务有效近似，不强制声称能复现任意不可压缩、断裂或塑性响应。

### 4.2 创新假设一：只收缩视频真正约束的后验方向

目标为联合条件分布 `q(z,η | I_0:T, Δt, 可选测量)`。概念上：

\[
p(z,\eta\mid I_{0:T})\propto
p(z\mid I_0)\,p(\eta\mid I_0)\,
p(I_{1:T}\mid I_0,z,\eta).
\]

静态先验负责类别与合理范围；动态项只对有响应证据的方向增加约束。实际先验可以联合建模 z/η；上式的分解是近似假设，不能默认为二者独立。动态证据需以首帧为条件，避免将同一外观信息重复计入两次而产生假精确。

训练阶段可计算观测 Jacobian。将材料和干扰因素的局部敏感度分别记为 `J_z, J_η`，噪声权重 W，则 nuisance 消去后的局部信息近似为：

\[
F_{\mathrm{eff}}=J_z^TWJ_z-
J_z^TWJ_\eta(J_\eta^TWJ_\eta+\Lambda_\eta)^{-1}J_\eta^TWJ_z.
\]

用谱分解提供可观测方向的训练诊断或更新正则：信息充分时缩小响应后验；信息不足时保留先验和多解。无需在测试时逐视频计算完整仿真 Jacobian。必须消融普通概率头、只看 `J_z`、消去 `η` 的版本，才能验证这一设计价值。

两个限制必须写进方法：局部信息秩不证明全局唯一性；人为很强的 nuisance 先验会制造“可辨识”，所以实测已知量和假定已知量必须分组报告。Jacobian 本身也需做时间步、扰动幅度和重复前向噪声检查。

**真正需要证明的新行为**：同一片段加重遮挡、去掉力/尺度测量或移除卸载阶段后，正确的不可辨识方向应变宽；增加有信息的交互后变窄，且未见动作预测相应改善。单纯让 GMM 输出宽一点不满足要求。

### 4.3 创新假设二：以未见干预响应定义跨引擎适配

使用 `θ_e = A_e(z, G, c_e)`。其中 G 是几何与结构；适配器可以处理本地离散表示，但不得让材质 latent 随相机、训练动作或数值步长任意漂移。

训练适配器最小化标准化探测响应距离，而非不同引擎标签数值的 L1：

\[
\mathcal L_{\mathrm{adapter}}
=\sum_{a\in\mathcal A_{\mathrm{cal}}}
d\big(\mathcal R_e(A_e(z,G,c_e),G,a),r(z,G,a)\big).
\]

独立的 `A_check` 包含未参与拟合的力方向、幅值、速率、支撑与卸载。**拟合同一段动作不是跨引擎材料迁移的充分证据。** 校准试样与测试对象也分开，防止 adapter 记住几何。

同时输出兼容本构 mask 和引擎近似误差 `ε_e`：某引擎即使使用最佳参数也不能达到的响应误差属于表示能力上限，不能全部责怪视频模型。可将适配器拆为明确的单位/本构映射与有界数值修正，并要求修正在网格/时间步收敛时稳定或减小。该约束比不受限的参数转换更可解释，但有效性仍要实验验证。

与 UniPixie 的区别应通过实验证明：其共享编码/多输出/离线匹配已有先例，我们新增的是**实际动态观测条件下、消去干扰后的响应后验，以及未见干预和数值变化下的保真/拒绝输出机制**。

对“新引擎”必须说明：未经标定的任意新求解器不保证零样本可用；可以研究冻结视觉编码器，只用 100/1,000 个标准响应校准 adapter 的少样本迁移，但不能把这部分数据隐去。

### 4.4 创新假设三：观测等价的多解蒸馏，而非回归一个任意拟合点

离线教师对同一视频联合搜索材料与 nuisance，保留多个满足观测容差、数值与物理质量门槛的解。对这些解施加未见动作，计算未来响应的分歧：

1. 原视频相近、所有测试动作也相近：可合并为当前任务下的等价解。
2. 原视频相近、新受力明显不同：学生必须保留该歧义；若允许补充视频，推荐能区分它们的动作。
3. 多个解都无法解释输入：提示本构不兼容、几何/追踪错误或分布外，不能用更大的置信度掩盖。

**多起点拟合解的出现频率不是贝叶斯概率。** 优化候选可用作可行集合和对照，不能直接当正规后验样本。概率训练应依托可追溯的模拟采样先验、nuisance 随机变量和条件密度估计，再用 simulation-based calibration / 留出真实数据校准；教师候选用于补充约束或蒸馏时须标注其近似性质。[SBC 方法](https://arxiv.org/html/1805.09294)。

本路线不要求预测密集应力/应变场再喂回。输入可为视频 token、时间、可见稀疏对应和不确定几何；仿真在离线教师、数据生产或可选的训练损失中使用。冻结教师和按需短 rollout 能降低训练成本。若某方法测试时需要仿真搜索，应另列为校准版，不能算进零优化前馈版。

## 5. 数据：优先增加可辨识结构，而不是增加静止帧

### 5.1 新合成数据的第一批受控设计

建议先验证一个小规模设计：12 种几何 × 16 组连续材料采样 × 4 种交互 = 768 个物理案例；两种匹配本构引擎共 1,536 次 rollout，每个案例渲染无遮挡/真实工具遮挡两版本，共 3,072 段视频。**这是预算提案，不是已生成数据，也不是足够规模的断言。** 网格/时间步标定和校准动作需额外计入成本。连续参数范围、几何划分和动作组合留出在生成前确定，不把有限参数网格背诵当泛化。

四种首批动作可用已知力压入—释放、不同方向加载、剪切、短时自由回弹；若引擎或边界未通过这些工况标定，就先缩小动作族。分别建立：

- 同几何/外观/加载，改变材料：阻断外观捷径。
- 同材料，改变几何/厚度/外观/动作：学习材性而非对象名称。
- 同表面，不同空心率/厚度；不同 E 调整成相近观测形变：暴露材料—结构混淆。
- 同视频观测近似一致、其他动作响应不同：直接监督保留多解的必要性。
- 同物理轨迹，真实工具前景/后景遮挡与无遮挡配对：将信息损失与材料变化分离。

材料的“相对软硬”排序只在几何和加载匹配时定义；跨空心/实心对象按像素位移排序会重新引入混淆。加载轨迹、力、反力、实际时间戳、质量、单位、体积、求解器版本均记录，缺失与不适用分开 mask。

### 5.2 遮挡与视频效率

训练时允许多视角/无工具渲染/接触测量给教师特权监督，学生仍只看部署允许的视频。使用真实有接触的手/夹具几何、不同遮挡位置、自遮挡、可见片段缺失，不能只随机盖黑块。对严重遮挡下不可恢复的信息，应输出更宽后验，而非保证靠增强恢复。

按加载、峰值、卸载、回弹分段采样 16–32 帧，保留物理时间；不要把所有静止尾段平均摊入训练。自由回弹即使位移变小，也可能包含 E/ρ、阻尼信息，不能仅以光流阈值一律删掉。记录去刚体运动后的局部形变、可见性和条件参数敏感度，联合决定是否有辨识价值。

### 5.3 外部数据各司其职

| 来源 | 建议用途 | 不能当作什么 |
|---|---|---|
| 原 DeformFieldBench | 历史基线、对象隔离、标签/加载审计、有限域预训练 | 未审计的真实物理应力或跨引擎统一 GT |
| ReconPhys 公共合成集 | 单视频前馈基线；自由落体/碰撞的独立外域 | 复杂戳压和混合材料真实性证明 |
| PIXIE / VoMP 公共部分 | 材料属性关联和静态先验；弱标签带来源权重 | 每个对象实测 E/ν/ρ；私有子集结果 |
| PokeFlex | 真实已知力校准、尺度/质量与动作留出验证 | 已公布四类本构完整 GT |
| Deform360 | 多物体真实运动/可见性预训练，特权多视角教师 | 每段具有独立实测材料参数 |
| PhysTwin 数据 | 真实操作者遮挡、逐物体拟合基准 | 完全未见对象的任意材性准确度 |

PokeFlex 包含 18 个对象、机器人戳压/跌落、同步 wrenches/接触位置。论文用 Hooke 定律和 RANSAC 估计 **148–2,156 N/m 的对象刚度**；这是有价值的力—位移信号，不能未经几何校正直接当 Pa 单位 E。[PokeFlex 论文](https://arxiv.org/html/2410.07688)、[项目](https://pokeflex-dataset.github.io/)。

Deform360 报告 198 个对象、1,980 次交互、41 台相机、215.7 小时多视角汇总与 2,330 万帧；这些不是同等数量的独立物理实验。重建和追踪含模型精化，应与独立测量 GT 区分。本项目仅准备的局部数据不能写成全量已训练。[论文](https://arxiv.org/html/2607.05390v1)、[代码/数据入口](https://github.com/lhy0807/deform360)。

不建议此时大批切换引擎。先用可做解析与收敛验证的 FEM/Warp 弹性小问题建立响应标准，再接已经通过相应工况校准的 MPM。当前 libuipc 复杂接触的部分收敛门槛仍未通过；它可以继续研究，尚不应生产“高质量力 GT”主训练集。Boba/Newton 等可作为并行 rollout 或统一接口候选，选型必须实测本构、接触反力、复合材料和网格收敛，而非只看演示帧率。

## 6. 模型、base 与训练：先做有效信息，再提高容量

建议结构：

```text
首帧外观/几何先验 ─────────────┐
视频时序编码＋可见稀疏对应＋时间 ├→ 联合材料/干扰因素分布
可选的实测尺度/质量/力及其 mask ─┘       ↓
                             标准干预响应后验
                                      ↓
                 引擎映射＋数值条件＋适用性/近似误差
                                      ↓
                       参数分布与未见交互预测
```

先维持 DINOv3-L/16 和已有严格无场 N0 控制，只改变数据结构和目标，便于定位因果。其后比较真正的视频编码器与逐帧 DINO 时序注意力：VideoMAE 系列是 MatPhys 已采用的可行起点；具体版本、许可证和检查点在实施时核验。不要把换 backbone 本身写为方法创新。优先冻结编码器或只训练后部 adapter/LoRA，待有足够有效视频再增加容量。

几何预测网络只能提供带误差的几何，不把单目生成深度当度量真值。若深度/多视角或力传感器在测试可用，单独建立增强输入赛道；若它们只在训练给教师，报告特权监督成本和公平控制。

训练目标分阶段：已知几何/加载的 oracle 条件辨识 → 加入 nuisance → RGB 学生蒸馏 → 未见动作/引擎条件一致性 → 真实视频校准。只在观测支持且标签合法时训练 SI 参数误差；其余使用响应分布、可行集合、缺失标签和校准目标。不要用强单点回归迫使不可辨识条件输出唯一真值。

工程上先解决 NF 训练约 12 秒中约 9.8 秒的数据等待（该等待包含在训练时间内，验证约 3.1 秒另计）。已有独立白名单避免场进入 GPU，但底层仍读取含旧场的 payload。下一步可生成独立紧凑无场缓存，校验特征与时间戳一致后再替换；配合持久 workers、分片顺序读取、批量教师候选与短时域 rollout。保持 BF16 数值核验，不能以降低物理精度换取虚假的高效教师。不要为这样的小模型盲目占满多 GPU。

## 7. 公平比较：参数准确、响应正确与速度分开检验

### 7.1 三种输入赛道

1. 单 RGB 视频：N0、强时序基线、可复现的 ReconPhys、我们的零优化学生。相同对象、帧、时间、split、可用相机信息。
2. RGB＋度量几何/深度/已知力：在线拟合与学生都获得相同增强输入，另与各方法原生最佳输入报告上界。
3. 静态资产先验：PIXIE/VoMP/UniPixie 类方法。若需要额外多视角资产或重建，应单独列出成本和信息；不能悄悄赠送而称同一单视频赛道。

MatPhys 必须区分公开检查点直接推断和 released per-case fitting；EgoPhys 必须计入 CMA-ES；UniPixie 未开放时可实现明确标注的结构控制，但不能将自建简化版命名为官方复现。

### 7.2 质量主指标

- **首要：未见动作的局部形变、表面轨迹、接触反力、自由回弹频率/阻尼、残余形变与跨引擎响应误差。** 不只预测原片段后 30%，还换加载方向、幅值、速率或支撑。
- 参数误差只在相同定义、单位、引擎/本构与可信标签下计算；对象有效刚度单列。不同引擎参数不能直接混合求 MAE。
- 用确定性的后验均值/中位数或事先规定的决策评估点预测；预测分布使用 NLL、CRPS/energy score、覆盖率及区间宽度。禁止 best-of-K 偷看真值选样本。
- 模拟后验用 SBC 诊断，真实数据按对象留出做覆盖校准；模拟校准不保证真实域可靠。边际与联合覆盖分别命名，包含 OOD 和引擎不兼容拒绝率。
- 按对象实例聚类置信区间；同一资产的材质/相机/动作变体不跨 split。先用单种子筛查，再在达到门槛的方向跑至少 3 seeds；冻结方案后只打开一次最终测试。

### 7.3 速度—质量曲线

在同一硬件、相同输入与初始化下，比较 0、10、30、120、600 秒在线预算：

- 零测试优化前馈；
- 前馈初始化＋1–5 次校准（单独命名）；
- 相同优化器默认/随机初始化；
- PhysTwin/NeuSpring 弹性、EMPM 弹塑性等可复现强拟合基线。

记录解码、分割/追踪、几何、网络、搜索、仿真分别耗时和总耗时，报告冷启动与模型常驻两种。离线数据、教师与训练成本也要公开；摊销盈亏取决于对象数量，不能把离线数百小时成本当作消失。在线拟合在病态条件下的参数也不是实测真值，其预测质量和不确定性都需检查。

### 7.4 最少且能检验创新的消融

| 版本 | 要隔离的问题 |
|---|---|
| R0 强视频直接回归；另保留最强无桥辅助控制 | 新方法是否超越认真调过的无桥基线 |
| R1 共享编码＋独立引擎头＋普通概率输出 | 已知多头/概率结构本身的收益 |
| R2 R1＋未见标准探测校准与适用性误差 | 响应约束是否真的带来跨引擎可迁移性 |
| R3 R2＋材料/nuisance 联合建模与可观测方向更新 | 是否缓解力/厚度混淆，概率是否随证据变化 |
| R4 R3＋观测等价多解及干预配对训练 | 多解是否改善未见动作分布，还是仅让区间变宽 |
| R5 R4＋配对真实工具遮挡的特权教师 | 信息损失时是否合理退化、覆盖和精度是否改善 |

所有版本使用相同可见输入、数据与预算；若新增数据/教师/参数量，加入得到同等资源的基线。场桥只作为额外对照，不用它的较弱版本来替代强 R0。

## 8. 按收益与风险排序的下一阶段验收

以下为**建议门槛，不是性能承诺，也不是已经完成的任务**。根据试点误差量级可在看最终测试前修订并留痕。

| 阶段 | 工作与反馈节点 | 继续 / 停止依据 |
|---|---|---|
| P0 可辨识性 oracle | 先用真几何/轨迹，分已知与未知力/尺度；检查等价解在新动作下分歧 | 若 oracle 都无法收缩目标方向，改输出目标或采集动作，不扩大 RGB 网络 |
| P1 引擎响应标定 | 解析夹具、重复前向、网格/时间步收敛；两引擎拟合动作外的检查 | 共同弹性本构下建议 p95 响应误差 <5%；若不达标，定位几何/边界/本构，暂不加第三引擎 |
| P2 小规模受控学生 | 上述配对数据，固定 DINO，先 R0/R1/R2/R3 顺序比较 | 相对最强 R0 未见动作误差改善建议 ≥10%，且对象配对区间支持改善后才扩大；训练停滞按已有早停直接结束 |
| P3 多解与遮挡 | R4/R5，分别去力、去尺度、遮挡、去卸载 | 检查覆盖与锐度、下游响应；不能靠无条件扩大区间过关 |
| P4 真实校准与外域 | PokeFlex 对象/动作留出＋少量真实对象；冻结后用最终测试 | 各输入赛道与在线强基线给质量—时间曲线；明确哪些参数只可给范围 |
| P5 扩材料/模型 | 黏弹性→塑性→2–4 组分及接口，必要时 video backbone 适配 | 仅在前阶段有效后扩展；否则优先修本构/观测，而不是堆容量 |

“接近在线”建议预注册为：在约定赛道、同一未见动作集合上，学生响应误差不超过强在线基线的 1.1 倍，并有显著测试耗时优势。若在线误差接近 0，使用与物体尺度/传感噪声关联的绝对容差，不能用无意义的比值；同时报告全部对象和失败尾部，不能只选容易案例。

最终有三种都应诚实接受的结果：

1. 零优化学生接近在线，同时显著优于强直接视频控制：支持主要目标。
2. 只有少步校准达到接近在线：形成快速初始化/少步系统辨识工作，不能称零优化解决。
3. 在足够激励、通过标定的数据上仍没有优势：不再坚持模块叙事，保留可辨识性与跨引擎误差基准的贡献，重新评估方法。
