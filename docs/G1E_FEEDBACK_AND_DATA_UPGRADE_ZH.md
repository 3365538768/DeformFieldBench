## 找到的瓶颈与修复

旧 G1d 全验证集门均值仅 2.04e-5，所有门值低于 1e-4。门权重除以有效帧数导致桥贡献整体接近零，偏置仍可学习常量修正。G1e 改为归一化 sigmoid 权重，加可微零场参照及输出偏置抵消。零场现在严格返回冻结 RGB；历史默认行为和 `model.py` 的缓存来源哈希保持兼容。

同一检查点 FP32 清空桥后的平均参数变化从约 1e-8 增至 0.1498；批内错配场后 MAE 从 0.78645 升至 0.79109。桥已经被使用，但不能据此证明物理因果关系，尤其时间反转的影响仍很小。O 相对 RGB 改善约 15.55%，而 D 仍落后 G。

Dice 让接触 IoU 从 7.98% 升至 13.11%，流图误差相对训练常量改善 17.47%；应力图反而较常量差 9.13%。旧场是颜色可视化，没有 SI 应力语义；不应继续仅靠延长训练解决其物理有效性问题。[D 场审计](G1E_D_FIELD_AUDIT.json)、[Dice 场审计](G1E_D_DICE_FIELD_AUDIT.json)。

目标审计：训练接触仅占 0.655%，121/512 条没有采样到接触；验证 30/128 条无接触。固定描述符的真场 ridge MAE 0.7074，全部置乱 0.9945，但同物体/本构内置乱仅升至 0.7413。GT 本构类别中心化后，E/ν 对类别均值的额外改善很小，ρ 反而更差。类别/外观/动作混杂不能当作连续材质辨识能力。该探针使用不等容量特征，只用于找问题，不作为方法排名。[目标审计](G1E_TARGET_AUDIT.json)。

工程效率继续复用经 SHA 验证的本地缓存，不重复计算 DINO 特征；此前已验证等价训练每轮 31.54 → 17.97 秒。G1e 新桥增加一次零参照计算，其收益与成本应单独测量，不能沿用旧速度声称本次同样加速。停滞组按既有验证规则退出，不因单步 loss 波动停机。

## 新引擎的实际发现

pyuipc 0.0.29 已在 `.engine-envs/uipc` 隔离安装，通过 A800 CUDA doctor。单四面体六场景通过已知力脉冲/总动量、撤力后动量保持、正体积和 dt 敏感性检查；最大相对动量误差约 1.19e-11，dt 减半后的最大位置差小于物体尺度的 0.14%。这不验证应力标签和复杂接触。

原生悬臂梁更严格的校准失败：粗/细解析位移误差 70.8% / 44.7%，网格变化 26.1%。发现安装轮子的 μ/λ 映射和上游当前 SNK1 校准不同。显式修正材料系数并进一步细化到 40×8×8 / 80×16×16 网格后，预先设置的六项梁验收门槛通过；细网格解析误差约 3.06%，E 加倍的位移比约 2。两种修改同时发生，尚未完成各自独立效应的分解。

物理正确性与吞吐不能兼得地假定：80×16×16 网格有 122,880 四面体，200 帧约 42–57 秒（小场景 A800 实测，含初始化，不是大数据集吞吐）。低分辨率标签可能系统偏硬；后续需要寻找满足误差门槛的较低成本网格或合适的高阶/降阶/MPM方案，而不是直接扩大低质量模拟。接触、复合界面、塑性、渲染与新动作重放尚未完成。

已进一步完成同条件 2×2 析因实验：原生/修正映射在 20×4×4 时解析误差 44.65% / 32.46%，在 80×16×16 时为 21.73% / 3.06%。同网格下修正映射使位移增加 22.0% / 23.9%，证实参数映射与网格误差均有独立影响。[记录](UIPC_MAPPING_GRID_ABLATION.json)。

## 开源数据与模型

- [Deform360](https://huggingface.co/datasets/brownu/deform360)：已固定版本，下载绳、橡皮筋、布、海绵、黏土五类各一段真实视频，全部哈希、完整解码和捕获时间戳通过。只作为真实运动预训练候选，未假设存在连续 E/ν/ρ 标签。[审计](EXTERNAL_VIDEO_AUDIT.json)。
- [PhysTwin](https://huggingface.co/datasets/Jianghanxiao/PhysTwin)：用约 5.9 MB Range 请求索引 8.08 GB 主 ZIP 的 41,554 个成员，读取 12 个小元数据文件。样例有相机内参、30 FPS、分辨率、帧范围与划分；尚未接入原生参数或视频。下载的 pickle 不执行反序列化。[接入回执](DATA_SOURCE_PILOTS.json)。
- [PokeFlex](https://pokeflex-dataset.github.io/)：优先研究已知交互力与形变响应；物体等效刚度不能直接当作 E。
- [Boba](https://github.com/jianxiapyh/Boba-Public)：候选高吞吐在线拟合控制，但弹簧网络参数需独立适配，不能直接和 FEM 参数拼接。
- [EMPM](https://github.com/rai-opensource/empm)：代码及构建/许可条件单独核查，目前 README 数据链接未完整可用，暂不作为已接入数据源。
- [DINOv3-L 官方权重](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m)：用户已申请访问，等待通知；当前代码不绕过 gated 权限，不改用随机权重冒充新主干。

A800 已按用户指示复用 4090 代理并验证 Hugging Face HTTP 200；凭据只在主机私有 0600 文件，项目提供 `scripts/with_proxy.py` 执行包装器。新数据、依赖环境和凭据均不进入 Git。

## 下一步执行顺序

1. 跨引擎原生 GT 隔离，并准备共享响应/专属参数头，详见 [adapter 方案与当前实现边界](CROSS_ENGINE_MATERIAL_ADAPTER_ZH.md)。现有单头训练阻止异构标签混合；原型尚未集成训练。
2. 材料系数修正、网格分辨率的独立效应已经初步分解；继续验证拉伸/剪切、接触、塑性和双材质界面。只有通过相应门槛的场景才生成度量标签。
3. 小规模同几何/外观、不同材料 × 同材料、不同载荷/边界的成对数据；显式记录力、尺度、质量、dt、本构和实际系数，按物体/材料配置隔离划分。
4. 原视觉场上先检验可预测的运动通道能否带来独有收益；新数据使用真实二维运动或度量响应，不把伪应力颜色当物理量。无场/特征控制同预算运行，停滞早停。
5. 多引擎共享响应与原生头集成后，先做受控双域对照；授权到达后再安排 DINOv3-L 主干对照，不把主干变化与 adapter 效果混在同一次结论中。
6. 冻结候选后才做多种子、独立测试、新动作重放和在线拟合强基线。当前没有证据声称接近在线拟合质量或远超无桥方法。
