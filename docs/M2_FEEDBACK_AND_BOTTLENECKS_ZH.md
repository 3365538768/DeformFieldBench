# M2 实测反馈与瓶颈分析（2026-11-08）

当前最主要的限制是**材料信息的可辨识性、诊断取样方式、运动场的表示和部署输入不一致**。已有证据不足以将问题归结为骨干太小或训练轮数少。M2 已完成，预测场能够影响材参输出，但仍未超过最强匹配无桥控制，不升级大规模确认实验。

## 已完成的证据

同一冻结 DINOv3 ViT-L/16、512 train / 128 val、88/10 个物体、seed17、同一 3,574,839 个可训练参数、相同初始化和优化器、有效 batch=8、最多20轮。测试效果未读取。MAE 是训练集标准化后的参数误差，不能当原论文 SPE、物理重放误差或相对百分比误差。

| 组 | 内容 | 最佳 MAE | 最佳轮 / 实际轮 |
|---|---|---:|---:|
| B | RGB，无场监督/反馈 | 0.699524 | 12 / 16 |
| C | 位移辅助监督，无场反馈 | **0.682811** | 17 / 20 |
| D | 预测位移与可靠性场反馈 | 0.686717 | 12 / 16 |
| G | 同容量普通特征反馈，保留场辅助监督 | 0.706286 | 9 / 13 |
| O | 输入 RGB 教师伪场，教师使用真物体 mask | 0.711283 | 13 / 17 |

D 相对 B 误差低约1.83%，但比 C 高约0.57%。D−C 的物体聚类 bootstrap 95% 区间为 **[-0.03685, 0.04812]**；10个验证物体、单种子且验证选模，这不是独立泛化结论。O 的结果不理想，只能说当前伪场＋编码方式＋训练方案没有产生额外收益，不能据此宣布真实物理场无用。

M2 的干预结果与旧版有明显区别：D 正常0.686717，零场桥0.865951，桥帧倒序1.080427。桥确实被使用，也保留了顺序；分布外干预本身不证明学到了物理因果。M1 的零桥几乎没有影响，不能继续用 M1 的“桥没用”解释 M2。

预测位移 EPE：C **2.847px**、D **4.007px**、零位移/训练常量8.376px，覆盖全部128条验证记录并排除确定零位移的首帧。D 能预测运动，却比 C 的运动估计差；材参损失与场估计之间可能存在取舍。这里的参照是 DIS 图像对应教师，**没有获得仿真位移、力或应力真值**。

## 1. 数据集：覆盖数、有效信息和可辨识性是三个问题

**当前512条不是原数据集能力的完整测试。** 快速筛查器按“物体×动作×本构”轮询抽样，本次恰好每个组合只选一条：512条对应512个组合，平均每物体5.8条，单物体1–11条。缺少同一组合内部的材料变化重复，可能不利于学习“几何和动作相同、材料变化带来响应变化”。完整训练清单有4,021条/88物体，1,242个组合，其中1,072个有重复；验证399条/10物体，其中108个组合有重复。结构性清单统计不涉及模型测试效果。

不能直接把这些重复记录当软硬排序 GT：E、ν、ρ、屈服可能一起变化；相同动作名称也不保证边界速度、尺度、重力、相机或阻尼相同。本轮已完成4,420条训练/验证元数据配对审计，比较 `external_actions.json`、`boundary_conditions.json`、数值设置及已导出的视角，元数据无缺失。严格匹配后训练侧只有352个重复组、可构成541对不重复使用样本的候选，覆盖87个物体；验证侧33组、48对、9物体。候选索引留在部署机 `data/manifests/material_pair_candidates.json`。只有元数据一致的候选可进入后续核验；没有固定其他变量的配对，不施加“E大就响应小”的无条件排序损失。没有候选的物体仍保留在完整评估，不能为方便配对而消失。

**原始运动多数能量是整体移动。** 对可靠对应区域、每帧至少32个有效56×56单元、排除首帧：去掉最佳常量平移后，训练/验证位移平方能量分别剩6.31%/5.30%。能量受大移动样本影响；逐片段剩余能量比例中位数为22.1%/23.4%，不能说94%的片段完全没有形变。验证帧的平均平移残差位移中位数1.81px，P90为5.29px。旋转、透视、追踪误差也属于残差，它不是应变真值。可靠单元数P10为0、中位数102；只有77.6%的验证非首帧达到32单元门槛。所有片段仍参与材参评估，不能删除困难样本来提分。

**加载方式限制绝对参数可辨识性。** 4,021条训练记录中3,178条（约79.0%）含速度驱动边界，其余843条有非零重力；已检查的外部动作导出均无显式力历史键。当前视频模型没有使用这些动作/边界向量。速度驱动不等于已测接触力，二值 force mask 也没有提供力幅值。在位移控制、缺少反力的准静态条件下，绝对 E 可能主要体现在反力而非形状；惯性条件中 E/ρ 等组合可能比 E、ρ 各自更可识别。具体仍取决于本构、接触、重力和边界，不能把所有数据一概判为不可辨识。应做已知设置下的参数敏感性与尺度变换重放，并允许输出参数区间/多解或统一响应。

**视觉多样性不等于物理多样性。** 旧 GS 外观有多样物体，但当前监督仍是全物体单组材参；空腔、薄壳、粘接界面和复合材料未被完整表达。现有规则体仿真用于标定，不构成真实物体覆盖。UIPC 接触反力收敛仍未过3%门槛，不能以扩大数据量替代质量验收。Deform360 已准备20物体，但无材参 GT、尚未训练；PhysTwin 的部分视频准备也不是官方优化器复现。

## 2. 架构：桥被使用之后，信息仍不够贴近材料响应

M2 修复了桥内时间平均、零场偏置及无标签第四通道自由编码的问题。但仍有以下限制：

- 图像路径为14×14 patch，时间注意力跟随固定4×4图像单元，没有显式沿物质点轨迹对齐；明显平移、遮挡和出视野会破坏“同单元=同部位”的假设。
- 当前场是当前帧→首帧的二维位移和对应可靠性，包含整体运动。它不是三维速度、应变、应力或接触力；首帧遮挡/距离较大时长程对应容易失效。
- 场损失只在可靠区域内监督，但场桥尚无显式的缺失观测聚合和几何/动作条件化机制。把可靠性当作物理接触会产生错误解释。
- 最终所有空间单元汇成单向量，输出全物体一组参数，不能表达区域材质、内部结构或多个材料界面。
- `EngineConditionedHeads` 与共享响应训练器只在 G2 完整观测场实验使用，**RGB 主训练器尚未接入多引擎头**。现有混合域拒绝机制避免了错误混标，不等于实现了跨引擎视频推断。

下一架构应将外观先验、整体运动、局部相对形变和加载条件分开：显式对应/轨迹 → 带可靠性的局部形变证据 → 共享响应及不确定性 → engine/version/law/solver 专属参数头。几何、相机和动作信息分别做有/无输入轨道；复合材质再使用空间场或区域参数头。先完成同信息的无桥/普通特征/场桥控制，再决定场是否提供独有价值。

## 3. Base model：已经很大，但目前主要作为冻结图像编码器

当前使用获授权的 DINOv3 ViT-L/16，只训练约357万参数的时序/场/材参头。冻结缓存便于快速、严格匹配的比较，却不允许骨干针对微小形变、遮挡或材质动力学适应。DINOv3 的 dense feature 能力不能自动视为视频对应或材料动力学能力；这一点来自当前使用方式，而非声称 DINOv3 一般不具备运动线索。官方接口见 [DINOv3](https://github.com/facebookresearch/dinov3)。

现有打包 RGB 为224×224；位移残差中位数约1.8px，而 patch stride 为16px。这提示细节瓶颈，但不等于断言 patch 无法编码亚像素变化。56×56场输出来自低分辨率特征插值，不能把输出尺寸当作真实细节分辨率。将现有224图像上采样到448也不会恢复缺失的原始细节；需核验原512渲染视频/序列是否仍可取得，或从几何重新渲染。

优先增加轻量像素/对应分支，再分别比较冻结 DINO 与末端1–2块小学习率适配。`observed_motion` 目前依赖冻结特征缓存，**先要解耦 RGB/标签读取，才能执行解冻实验**；直接改 `train_last_blocks` 会与缓存契约冲突。静态先验当前 `use_prior=false`，还没有检验静态与动态互补。独立静态先验需同样提供给无桥组。

对应教师可候选比较 [RAFT](https://github.com/princeton-vl/RAFT) 的稠密光流与 [TAP 系列](https://github.com/google-deepmind/tapnet) 的点轨迹/遮挡输出。官方资料已通过现有代理核查并保存来源 SHA；这两者尚未安装、运行或证明优于本项目 DIS。任何新教师先在相同渲染对应和遮挡分桶验收，再评估真实视频，不能仅用自一致性充当准确率。

## 4. 训练流程：当前是方向筛查，存在目标取舍与数据搬运开销

M2 使用固定学习率3e-4、场权重0.1、从零联合训练、无场预热；这不是对架构最优能力的充分搜索。D 的场 EPE 比 C 高约41%，提示联合材参目标可能扭曲运动预测，或者阶段/尺度不匹配。训练集32条、8个固定 batch 的局部梯度诊断：投影层两种监督平均余弦-0.0168，加权场梯度/材参梯度范数约0.100；场解码器平均余弦+0.0183、范数比0.358。接近正交，**没有强证据证明持续严重的梯度冲突**，不应直接把 PCGrad 当作已确定的解决方案。

优先小型、预先固定的阶段对照：运动头先达到训练/验证常量基线要求；再比较冻结运动头、只断开材参到运动头梯度、端到端联合。所有模型使用相同的预训练数据/教师/总步数与各自合理的优化控制。B/C/D/G 必须保留，不能通过删除强辅助监督组来获得场桥收益。

逐参数结果也限制“整体材质理解提升”的说法：D 的 E MAE0.5554，C0.5899；D 的ν0.6241、ρ0.8245，均不如 C 的0.5854、0.8127。E 的约5.85%优势是本轮事后分项诊断，不能替代预注册整体指标。密度和屈服尤其需要对应加载/惯性/塑性证据；没有激励时不应强求精确点估计。

效率上，D 每轮中位训练段18.40s，其中主进程等待数据12.62s，验证5.12s。等待包含在训练段内，且不是精确 GPU 空闲计时，不能与训练段相加。当前单条 DINO 特征实际为FP32、38.5MB，另读约5.3MB旧场/mask及新的运动覆盖；五组并行容易受读盘、反序列化、IPC和内存拷贝限制。缓存预算0时 worker 每轮重建；只增加 GPU 或 batch 未必解决。

下一效率实验先比较轻量特征/标签分离、经逐元素/预测 parity 验收的FP16/BF16存储、有界内存缓存与 persistent workers。原FP32缓存保留，索引记录新精度/父缓存哈希；不在同一实验中途切换。既有4 workers加载基准快约1.42倍，不等于训练全流程加速1.42倍。恢复时还需验证随机状态、样本顺序和缺失mask，不能只检查能继续迭代。

## 5. 比较方法：当前主指标还没有回答最终问题

当前 MAE 只回答同一旧引擎标签域下的参数预测，未证明“参数放进不同引擎后的响应好”，也未与在线优化系统公平对齐。主要缺口：

- **单视频部署**：训练默认三视角、无 view dropout。固定仅第0视角时，D 的 MAE0.82647，比三视角高约20.35%；B0.75515、C0.82684、G0.78103。D 在三视角上的优势不能移用于单视频。该结果是未重训输入干预，不是专门训练的单视角模型上限。
- **采样鲁棒性**：仅保留8个等间隔时刻时 D0.72117、C0.83013；这些输入分布变化不能拿来替代正式匹配训练。应以真实时间、动作事件采样和训练时视角/帧缺失增强验证。
- **共同信息**：RGB-only、已知几何/尺度/动作、RGB-D/实测力分轨；伪标签使用真mask的离线成本与信息要披露。PhysTwin 官方流程使用RGB-D并逐场景优化，不能直接与RGB前向参数MAE排名。见 [官方流程](https://github.com/Jianghanxiao/PhysTwin)。
- **共同终点**：固定几何/边界，评价未见作用的轨迹/轮廓/恢复及原生参数误差、失败率和尾部。各引擎分别拟合统一响应，不横比未经校准的 E、spring k 等数值。
- **共同预算**：本机统一端到端0/10/30/120/600秒或rollout预算，比较从零优化、无桥初始化优化、场桥初始化优化、纯前向；重建/跟踪/优化/渲染均计时，离线训练成本另报。
- **独立证据**：当前只有10验证物体，反复用于选方案，三组配对区间都含0。方向通过后做seed17/29/43和冻结测试；尚不进入“远超无桥/接近充分在线拟合”的结论。

当前匹配容量的 B/C 仍执行被置零的桥模块，便于训练对照，但不是经过推理裁剪的最快无桥实现。正式成本比较必须允许各方法跳过无用分支，不能用当前诊断脚本的额外开销制造速度优势。

## 下一步顺序与停止条件

1. **先修数据与输入协议**：利用已有4,021条的元数据候选，构造保留材料重复的诊断训练清单；固定验证协议，至少保持物体覆盖和样本预算可比。单视频作为主轨训练，多视角单列增强；动作/边界条件作为额外信息轨，不隐式混入 RGB-only。
2. **再检验可辨识性**：从已知动作、几何、相机和本构的少量受控重放开始，改变 E/ρ/ν/屈服/阻尼，检查响应敏感性及多解。若目标参数不敏感，评价统一响应和区间；补反力/尺度证据后才恢复绝对参数目标。
3. **改运动与响应表示**：区分整体移动与局部相对形变；短程对应＋长程轨迹和遮挡mask；字段空间token和统一响应监督；端到端/冻结运动头配对比较。DIS通过30/32简单渲染验收不代表真实手/夹具遮挡已解决。
4. **有依据地利用骨干/公开数据**：小学习率末块适配、像素分支、Deform360无标签运动预训练；所有控制共享这些增益。[PokeFlex](https://pokeflex-dataset.github.io/)优先补真实加载证据。无标签视频不创建材参GT，保留跨来源/资产隔离。
5. **接视频共享响应与引擎头**：先用已标定协议，逐引擎/版本/本构/数值设置归一化。新引擎隔离环境验收；原生标签不能直接合并。接触力/能量未验收的案例只提供相应用途标签，不扩量污染训练。
6. **最后做确认与在线比较**：最强无桥控制不移除；通过方向门槛后才扩三种子和独立测试。平台期继续按既有策略早停，无效路线保留负结果。
