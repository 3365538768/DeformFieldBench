## G1c：冻结 RGB 基线，学习局部场带来的修正

新架构位于 `fieldbridge.local_model.LocalResidualModel`，配置 `architecture=local_residual`。旧架构和 `model.py` 保持不变，旧检查点仍可读，冻结 RGB 特征缓存的原来源校验仍然有效。

1. 从同一个 G1 B 最佳 RGB 检查点初始化并冻结 RGB 主干、投影、时序编码器和参数头；冻结分支始终保持 eval。初始化时严格验证旧架构、无反馈、无先验、数据清单、train 统计和骨干 SHA。
2. 额外的空间卷积和逐位置时间卷积适配器只服务于场分支。对无效帧先遮罩，再做时间卷积，避免填充污染邻帧。
3. 场编码保留 4×4 空间格点，用 RGB 上下文查询局部场，再做每个视角内的时间注意力和学习权重聚合。视角聚合保持置换不变，完全无效视角不会产生全遮罩 NaN。
4. 参数和本构类别修正头从零输出开始训练；权重聚合只是可训练门控，不声称是经过校准的置信概率。特征反馈控制使用同样模块和参数量。
5. 训练前保存第 0 轮验证结果和完整 RGB 回退检查点。只有更好的联合验证结果才替换 `best_material.pt`。如果第 0 轮胜出，明确报告“没有学到有效修正”，不能将保持基线当成提升。恢复第 0 轮检查点也经过测试。

架构图：

```text
视频 → 冻结 RGB 编码器/时间编码器 → 冻结 RGB 参数估计 ──────┐
                  │                                     + → 参数预测
                  └→ 可训练局部/时间适配 → 场预测          │
                          → 空间格点注意力 → 时间注意力 → 零初始化修正头
```

## 七项任务与公平性

| 任务 | 作用 |
|---|---|
| field_fit | 仅取 64 个训练样本，检查局部场分支是否可拟合，不访问 val/test |
| C_frozen_rgb | 保持 RGB 输出，仍训练相同辅助场分支 |
| D_local_fields | 使用预测场的局部时序修正 |
| G_local_features | 同容量、同预算的直接特征修正控制 |
| D_local_detached | 截断场输入处的材质梯度，辅助监督仍训练场分支 |
| O_local_oracle | 真场上界，仅特权诊断 |
| S_local_shuffled | 同 split 跨物体真场置乱，检查正确场对应关系是否必要 |

六组材质对照统一 512 train / 128 val、seed 17、固定冻结骨干、同一 RGB 起点、场权重 0.1、接触平衡 BCE、batch 4 / accumulation 2、最多 24 epochs、前 2 轮场预热。联合阶段最少观察 6 轮，连续 4 轮没有 0.2% 相对改善就早停。暂停只在完整检查点生效，恢复保留优化器和随机状态；每组保存独立输出目录。

field_fit 独立使用 evenly spaced 的 64 个训练样本，样本及目标来自原来训练清单和训练统计，GT 字段仅用于监督。最多 20 epochs / 320 更新，lr=0.001，场权重 1；这是刻意的小样本拟合检查，预算与材质对照不同。每轮同时记录训练场 MAE、接触 IoU 和召回，连续 4 轮场 MAE 无实质改善（至少 5 轮观察）则结束。不能把这些训练指标与 G1 的验证指标混作泛化改善。

RGB 起点来自先前在同一验证集上选择的检查点，G1c 继续用这个验证集调参。因此本阶段是开发证据；即使改善，也不能直接宣称独立测试或真实世界优势。G1c 没有改变原数据的物理单位、尺度或阻尼混淆问题。

## 反馈与失败出口

- 启动后先核对六组第 0 轮与原 B 的 0.79995 一致。真实双 GPU 预检已完成，验证 128 个样本无漏项/重复；这次预检只有两次优化更新，不作为性能结果。
- field_fit 若不能充分降低训练误差，优先检查目标编码、空间分辨率、时间对齐、前景/接触掩码和预测器容量，而不是增加正式训练预算。
- 材质对照全部完成后生成 `docs/G1C_RESULTS.json`。D 必须同时超过 RGB、C 和 G 至少 2%，才路由到独立种子复验；保留第 0 轮不算成功。O/S 用来解释上界和语义信息，不作为可部署方法。
- 若仍失败，结合场拟合曲线与 O/S 差异决定先修字段质量、重建度量场，还是换预测器。随后再进入实际引擎标定、新动作响应、外部真实数据和静态先验；目前这些真实仿真/真实视频目标仍未得到验证。
- 不自动恢复旧 giant 全量 C/D。stage 路由、样本数、训练拟合进展和单组控制均显示在网页；默认筛选 G1c。

## 复现与验收

```bash
# 已准备 G1 数据/权重/字节一致本地缓存，且已完成 G1b 的 A800 项目根目录：
python scripts/setup_g1c.py --register
# 重载唯一的 optimization_manager；文件锁禁止重复实例。

# 也可独立训练：
python -m fieldbridge.train --config configs/g1c_D_local_fields_seed17.json
python scripts/overfit_fields.py --config configs/g1c_field_fit_seed17.json
python -m fieldbridge.cli evaluate --config configs/g1c_D_local_fields_seed17.json \
  --checkpoint runs/g1c_D_local_fields_seed17/best_material.pt --split val --output runs/g1c_D_local_fields_seed17/review_val
```

新克隆仍需准备真实数据、官方冻结骨干权重，以及本阶段使用的历史 RGB 起点。`setup_g1c.py` 不加 `--register` 只生成配置；不会自动创建或伪造历史结果。

验收包含：原 RGB 零修正一致性、冻结权重不变、材质梯度能到达场分支、视角置换/无效视角/填充帧不变性、部署输入拒绝 GT 字段、控制组参数量一致、第 0 轮检查点暂停恢复、回退不算改善，以及既有精确恢复/分布式覆盖等。A800 完整测试 27 项通过；另有真实双 GPU 训练/验证预检。紧凑检查点和审计入口均支持新架构。
