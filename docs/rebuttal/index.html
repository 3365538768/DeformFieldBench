为什么族内散点看起来不相关

仿真器只让比值可见，而原数据的阻尼把动态抹掉了

R2 · 尺度不变 1.2 × 10−6

E、ρ、σy 同时 ×4 后，所有粒子轨迹的相对 RMS 变化。单独 E×4 为 0.47、单独 ρ×4 为 0.39。只有 E/ρ、σy/ρ 可从视频辨识，ρ 本身不可辨识。

docs/r2/MPM_IDENTIFIABILITY_jelly.json
P4a · 阻尼 < 1%

V1 视频中 8 Hz 以上的运动能量。上游 grid_v_damping 每个子步施加一次，jelly 每秒速度衰减到 5×10−5，释放后 0.3 s 内静止，运动几乎全是位移控制的准静态。这也解释了 AKYF 指出的回弹 < 5%。

docs/notes_r.json（11-11 P3 / P4a 条目）
P1 · 标签先验 −0.84

jelly 训练标签中 ln ρ 与 ln(E/ρ) 的相关。V1 里族内 ρ 相关 0.4–0.6 来自这个采样先验，不是模型看见了密度；P4d 把 ρ 独立采样后，族内 r(ρ) ≈ 0。
