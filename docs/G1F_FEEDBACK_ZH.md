# DINOv3 对照结论与下一步

512 train / 128 val、物体隔离、seed 17；测试集未使用。下表为相同 DINOv3 RGB 初始化的最佳验证标准化 MAE，越低越好；只是诊断，不是独立测试。

| 设置 | 验证 MAE |
|---|---:|
| RGB | 0.805450 |
| 预测场桥 D | 0.802526 |
| 等容量特征控制 G | 0.802460 |
| 特权真场 O | 0.690323 |
| 置乱真场 S | 0.801946 |

预测场桥未优于等容量特征控制，置乱控制也相当。更换大骨干未解决场监督瓶颈，不继续扩大旧配置训练。RGB/D/G/S 按原有平台期规则早停；O 完成 24 轮。这不证明 field 思路无效：真场提供可观诊断上界，但不能作为推断性能。

对 D 的完整验证集场审计，常量基线只用全部 512 个训练样本拟合：接触召回 99.51%，精度 6.17%，IoU 6.17%；流场 MAE 0.156665，常量 0.140702，差 11.35%；应力编码图改善 7.63%。旧场是 RGB 可视化编码，不是 SI 物理量。FP32 清空桥后预测平均变化 0.1094，翻转时间仅 0.0000774，说明修正会使用桥输入，但时序依赖弱，不能据此声称有因果材质理解。

下一步先解决“什么场值得预测、跨引擎怎样比较”。G2 用两个实际求解框架在已知几何、SI 载荷、相同边界下生成匹配响应，并给各引擎独立参数 codec 和输出头。输入完整观测位移场的受控适配实验通过后，再接 RGB/视频预测场、几何尺度与载荷不确定性；不把受控场结果冒充视频结果。

原始证据：`G1F_RESULTS.json`、`G1F_D_FIELD_AUDIT.json`、`G1F_D_SENSITIVITY.json`。
