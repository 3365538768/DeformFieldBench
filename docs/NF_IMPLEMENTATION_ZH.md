# 零场材料系统辨识：实现与实验合同

本路线不预测稠密物理场，不使用接触/光流/应力辅助损失，也没有场或特征反馈支路。它与历史G控制不同：历史G仍接受辅助场监督。当前先用现有固定512训练/128验证、88/10物体、单摄像机16帧和冻结DINOv3-L/16验证实现；最终测试集不使用。

## 已实现

- `DirectVideoModel` 独立继承 `nn.Module`，只实例化冻结帧编码器、特征差分、局部时序注意力、空间位置、材料与后验/本构头；没有场头、场编码器或场反馈。差分是视觉特征差分，不称为速度/应变。
- `FieldFreeDataset` 从既有缓存严格白名单提取features/valid/times；旧缓存虽在磁盘上包含场，但返回值、内存缓存、IPC、GPU及损失中均无fields/field_mask。参数标签按原训练统计编码，不从旧缓存复制目标。后续可生成物理分离缓存，但本轮不改变特征精度。
- 首个有效帧的DINO全局特征训练固定配方ridge先验。训练样本按物体做五折OOF，验证先验只由全部训练物体拟合；先验不是PIXIE/VoMP集成，也不假设外观与旧随机材参存在对应关系。先验残差方差仅为未校准估计。
- 四分量对角高斯混合后验；缺失参数通过边缘化计算联合NLL。点估计为混合均值，评价另保存分量；区间通过精确边缘混合CDF数值反演，不以矩匹配高斯覆盖率冒充混合分布覆盖率。
- 离线教师overlay合同支持每样本1–16个解与权重，限制train-only并要求输入、求解器、拟合协议和响应核验来源。配置未提供准入教师时禁止蒸馏；恢复时检查先验、教师和特征索引SHA。
- 沿用项目逐轮验证、验证材参平台期早停、完整检查点暂停/继续、优化器/RNG恢复、Web队列与逐轮计时。

## 顺序控制

|实验|静态先验输入|参数Huber|混合NLL|物理场或反馈|
|---|---|---|---|---|
|N0_video_point|读取相同文件但内部屏蔽|是|0|无|
|N1_prior_point|物体OOF先验|是|0|无|
|N2_prior_posterior|相同物体OOF先验|是|0.1|无|

三组实例化相同模块、相同初始化与可训练参数数量；N0/N1未训练的后验头不用于可信区间结论。统一seed17、width256/layers2、lr3e-4、batch4×accum2、workers4、最多20轮、patience4/min6。顺序依赖为先验准备→N0→N1→N2→审计，不根据前组效果临时更改后组配方。单种子只作方向与工程诊断；历史强控制继续保留，不能因新控制较弱而删除。

## 离线教师验证的边界

`probe_fieldfree_teacher.py` 在I1已通过的线性小应变夹具上运行：已知几何、加载、尺度、nu=.3和rho=1000，仅拟合E。模拟16帧准静态投影轨迹，加入0.002px噪声；每条由有界逆拟合生成E教师标签，96条训练、24条留出。学生输入压缩轨迹观测和已知力，不是RGB视频，不用于原数据训练。

原GS数据尚未满足可信教师所需的几何/加载与响应核验，因此本轮不注册伪装成“教师蒸馏”的GT回归实验。该路线已完成接口与独立夹具验证；原视频的教师生成、蒸馏及真实新动作验收仍待完成。

## 验证与复现

关键测试覆盖：缓存中毒场无法进入训练、模型无场模块、缺失先验消除、OOF本物体泄漏拒绝、特征来源不一致拒绝、精确混合边缘NLL与分位数、未准入/非训练教师拒绝、完整训练/恢复与SHA变更拒绝。

部署机已有原诊断清单、DINO权重与缓存后：

```bash
python -m pytest tests -q
python scripts/setup_fieldfree_controls.py
# 由现有 optimization_manager 顺序运行；配置与权重不随文档伪造。
```
